02

처리 목적과 개인정보 항목

이름·전화번호를 입력하는 회원가입 기능은 없습니다. 사용하는 기능과 선택에 따라 다음 정보를 처리합니다.

지역 날씨와 생활 안내

항목 선택 지역·예보 격자·지역 코드, 위치 선택 방식, 현재 위치 기능을 허용할 때의 위도·경도·정확도·측정 시각, 요청 시각과 네트워크 정보

목적 지역 날씨·강수·대기질·도로·낙뢰 등 자료 조회, 가까운 관측 지점 선택과 생활 안내 제공

방법 이용자의 지역 선택, 기기 위치 기능과 앱·서버 통신. 수동 선택에서는 선택 지역을 기준으로 조회하며 현재 GPS를 알림 지역으로 자동 적용하지 않습니다.

백그라운드 위치 갱신 · 선택 기능

항목 앱을 사용하지 않을 때 이동 감지로 확인한 최신 위도·경도, 정확도, 측정 시각과 알림 지역 격자

목적 이동한 지역의 날씨·낙뢰 알림과 홈 위젯 위치·날씨 갱신

방법 초기 권한 안내 또는 설정에서 별도로 동의하고 위치 권한을 항상 허용한 경우 iOS의 큰 위치 변화 감지와 Android의 실행 알림이 표시되는 위치 서비스로 감지합니다. Android는 GPS 측정을 요청하며 배터리 사용이 늘 수 있습니다. GPS 모드·전체 알림·서버 사용이 켜진 동안 동작합니다. 개인별 이동 경로 이력을 만들지 않고 최신 위치를 갱신합니다. 정밀 위치 조건을 충족하지 않으면 서버에는 지역 격자만 등록합니다. 기기의 최신 미전송 측정은 암호화해 보관하며 15분보다 오래된 측정은 서버에 반영하지 않습니다.

주소 검색과 지역명 변환 · 선택 기능

항목 주소 검색어, 선택한 도로명·지번 주소, 주소 변환에 필요한 좌표, 접속 IP·요청 시각·브라우저/기기·네트워크 정보

목적 주소에 해당하는 예보 구역 선택, 현재 GPS 위치의 행정지역명 표시

방법 주소 검색어는 카카오 우편번호 검색에, 선택 주소는 Android/iOS의 주소 변환 서비스에 전달됩니다. 현재 위치의 지역명을 찾을 때는 해당 좌표를 플랫폼 주소 변환 서비스에 보냅니다. 주소 검색으로 얻은 상세 주소와 검색 좌표는 날씨챙겨의 기기 저장소나 날씨 서버에 저장하지 않고 선택한 예보 구역·표시 지역명만 저장합니다. 외부 서비스가 처리하는 접속·검색 정보는 해당 업체의 정책에 따릅니다.

웹 날씨 판단 구역 지도

항목 지도 페이지 접속 IP, 요청 시각, 브라우저·기기·네트워크 정보와 요청 출처 도메인

목적·방법 네이버 지도 스크립트·타일로 행정지역명·도로·지형과 기상청 예보 격자를 표시합니다. 지도는 기기 GPS 권한을 요청하지 않고 검색한 지역명·격자 선택을 페이지 안에서 처리합니다. 카카오 주소 검색은 이 지도와 별도의 기능입니다.

서버 등록과 날씨 알림

항목 무작위 설치 식별자, 설치별 인증정보의 해시, FCM 토큰, 지역·위치 정보, 알림 설정, 플랫폼·앱 버전·시간대, 호환용 연령정책 표시와 버전·서버 기록 시각, 마지막 사용 확인 시각, 알림 발송 이력과 중복 방지 상태

목적·방법 앱의 서버 등록·조회·설정 저장·알림 처리에서 설치별 요청 인증, 설정 동기화, 날씨 알림 전달, 중복 방지와 삭제 처리를 위해 수집합니다. 호환용 연령정책 표시는 본인 인증에 사용하지 않습니다.

앱 이용 통계 · 선택

항목 앱 이용 이벤트, Firebase 앱 인스턴스 식별자, 대략적인 지역, 기기·운영체제·앱 정보

목적·방법 이용 현황 분석과 기능 개선을 위해 별도 동의한 뒤 Firebase Analytics로 수집합니다. 정확한 좌표와 날씨 서버 설치 식별자를 분석 이벤트에 추가하지 않습니다. Analytics의 광고 관련 저장·개인화 동의는 기본 거부이며 광고 SDK의 동의와 별개입니다. 전송된 통계 삭제를 요청하면 앱 인스턴스 식별자를 인증된 날씨 서버에 보내 Google 삭제 API에 전달합니다.

광고와 광고 개인정보 선택

항목 IP와 이를 이용한 대략적 위치, 광고 요청·노출·상호작용, 기기·앱 정보, 성능·오류 진단, 광고 식별자·앱 집합 식별자 등 SDK가 처리하는 식별자, 광고 개인정보 선택 상태

목적·방법 Google AdMob·Mobile Ads로 광고 제공·측정·부정 이용 방지를 처리하고 UMP로 필요한 광고 개인정보 선택을 확인합니다. 운영용 광고 설정이 있으며, UMP가 광고 요청 가능 상태를 반환한 경우 SDK를 초기화하고 광고를 요청합니다. 동의 화면 표시와 제공 광고의 종류는 지역·설정에 따라 다릅니다. Android는 광고 ID 접근 권한을 포함합니다. iOS에서는 현재 앱 추적 투명성(ATT) 권한을 요청하지 않습니다. 이는 광고 관련 정보가 전혀 처리되지 않는다는 뜻은 아닙니다.

광고 제거 구매와 복원 · 선택

항목 상품 식별자, 구매·복원·취소 상태, 스토어가 앱에 제공하는 거래 식별자·시각·거래 검증 정보, 기기에 저장한 광고 제거 소유 여부

목적·방법 Google Play/App Store의 구매·복원 기능으로 광고 제거 권한을 확인합니다. 소유 상태는 기기 보안 저장소에 저장하며 다시 조회할 수 있습니다. 현재 날씨 서버로 구매 영수증이나 결제수단 정보를 전송하지 않고 카드번호를 직접 수집하지 않습니다. 스토어의 결제·거래 기록 처리는 해당 스토어의 약관·정책에 따릅니다.

운영 로그와 개인정보 문의

로그 항목·목적 요청 식별자·시각·API 경로, 인증정보에서 해시로 유도한 기기 구분값, 예보 격자, 좌표 포함 여부, 응답 상태·처리 시간·자료 상태와 오류 종류를 장애 확인·보안·서비스 운영에 사용합니다. API 애플리케이션 로그에는 인증 비밀값·FCM 토큰·정밀 좌표의 원문을 의도적으로 기록하지 않습니다. Cloudflare 등 네트워크 제공자는 접속 IP 등 전송·보안 정보를 별도로 처리할 수 있습니다.

문의 항목·목적 이메일을 보내면 발신 주소·문의·회신 내용과 처리 기록을 문의·권리 행사·고충 처리에 사용합니다.

03

동의, 권한과 거부 방법

  • 위치: 기기 설정에서 위치 권한을 변경할 수 있습니다. 거부해도 행정지역이나 예보 격자를 직접 선택할 수 있으며 현재 위치·정밀 위치 기반 안내는 제한됩니다.
  • 백그라운드 위치: 초기 안내의 ‘동의하고 계속’ 또는 설정의 ‘백그라운드 위치 갱신’에서 별도로 동의합니다. 동의 전에는 꺼져 있고 ‘백그라운드 제외’를 선택할 수 있습니다. 기능·전체 알림을 끄거나 직접 지역을 선택하거나 서버 데이터를 삭제하면 감시를 중지합니다. 항상 위치 권한도 철회할 수 있습니다. 절전·강제 종료·네트워크 상태에 따라 갱신이 제한될 수 있습니다. 감시 중지는 서버의 마지막 위치 삭제와 다릅니다.
  • 주소 검색·변환: 주소 검색을 사용하지 않고 행정지역이나 지도에서 예보 구역을 직접 선택할 수 있습니다. 위치 권한을 거부하면 GPS 지역명 변환도 사용하지 않습니다.
  • 알림: 앱과 기기 설정에서 끌 수 있습니다. 거부해도 앱을 열어 지역 날씨를 볼 수 있습니다.
  • 이용 통계: 설정의 ‘앱 이용 통계 수집 (선택)’에서 별도로 동의합니다. 거부해도 날씨·알림 기능은 제한되지 않습니다. 철회하면 이후 분석 수집을 중단하며 전송된 통계는 별도 삭제 요청으로 처리합니다.
  • 광고: UMP에서 필요한 선택을 제공하며, UMP가 요구하는 경우 설정에 ‘광고 개인정보 선택’이 표시됩니다. Android의 광고 ID 삭제·재설정 등은 기기 설정에서도 관리할 수 있습니다. 분석 수집을 끄는 것만으로 광고 관련 수집이 모두 중단되지는 않습니다. 광고 제거 구매가 유효한 경우 앱의 광고 표시·신규 광고 요청을 중지하지만 과거 광고 데이터나 스토어의 거래 자료를 삭제하지는 않습니다.
  • 구매: 광고 제거 상품을 구매하지 않아도 날씨 기능을 이용할 수 있습니다. 구매·환불·스토어 계정 자료는 Google Play/App Store에서 관리합니다.
  • 외부·국외 처리: 필수 API 전송과 웹페이지 제공에 필요한 Cloudflare 처리를 거부하려면 앱·페이지 이용을 중단할 수 있습니다. 통계·주소 검색·구매는 해당 기능을 선택하지 않을 수 있습니다. FCM 알림은 끌 수 있습니다. 광고 관련 선택과 권리 행사는 UMP·기기 설정·Google의 개인정보 도구를 이용할 수 있습니다.

권한 철회, 서버 등록자료 삭제, 기기 데이터 삭제, 외부 업체 자료 삭제는 각각 범위가 다릅니다. 서버 자료 삭제 후에도 식별자·정밀 좌표 없는 지역 날씨 조회와 별도 외부 SDK 처리는 계속될 수 있습니다.

  1. 설정에서 전송된 이용 통계 삭제 요청을 선택합니다.
  2. 수집 중단과 범위를 확인한 뒤 요청합니다.
  3. Google 접수와 기기 초기화 결과를 확인합니다. 접수는 외부 시스템의 실제 삭제 완료와 다릅니다.

서버 자료 삭제 후에는 ‘서버 기능 다시 사용’을 직접 선택하기 전까지 자동 재등록하지 않으며 다시 사용해도 알림을 자동으로 켜지 않습니다. 식별자·정밀 좌표 없는 지역 날씨 조회는 가능하고 광고·플랫폼·스토어 처리는 별도입니다. 앱 제거나 알림 권한 해제만으로 서버 자료가 즉시 삭제되지는 않습니다.

광고·스토어·플랫폼의 자료는 해당 업체의 개인정보·계정·구매 관리 창구에서도 요청할 수 있습니다. 서버 삭제만으로 구매가 취소되거나 환불되지 않습니다. 로그·이전 백업 등 사본의 삭제·보관 현황은 운영자에게 별도로 문의할 수 있습니다.

권리 침해 상담·신고는 개인정보침해신고센터(국번 없이 118) 또는 개인정보분쟁조정위원회(1833-6972)를 이용할 수 있습니다.

09

안전성 확보 조치

운영 앱 API는 HTTPS를 사용하며 서버는 설치별 인증 비밀값의 원문 대신 해시로 요청을 확인합니다. 기기의 인증정보·일부 동의/구매 상태·미전송 위치 등은 보안 저장소나 플랫폼 암호화 저장을 사용합니다. 자체 서버와 백업은 접근 권한을 제한하며 운영·시험의 사용자 자료를 분리합니다. Analytics는 기본 비활성이고 별도 동의에 따라 제어합니다.

현재 앱에는 연령 확인에 따른 외부 SDK 차단 기능이 없습니다. 또한 로그와 이전 백업의 보존 상태는 04에 공개한 대로이며, 이 방침을 게시하는 것만으로 오래된 사본이 삭제되지는 않습니다. 보안 사고가 확인되면 관계 법령에 따라 통지·신고하고 피해 최소화 조치를 합니다.
