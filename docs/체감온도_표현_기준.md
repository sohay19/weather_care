# 체감온도 계산·표현 기준

- 기준일: 2026-08-21
- 적용 범위: 서버 기상청 Provider, 앱 기상청 직접조회, Main 체감 문구
- 목적: 숫자 산식, 사용자가 느끼는 표현, 재난 위험 신호를 서로 혼동하지 않고 함께 사용한다.

## 1. 현재 채택 기준

### 숫자 체감온도: 기상청 공식 산식

[기상청 기상자료개방포털 체감온도 설명](https://data.kma.go.kr/climate/windChill/selectWindChillChart.do)에 따라 계절을 구분한다.

- 여름철(5~9월): 기온, 상대습도, Stull 습구온도를 이용하는 2022-06-02 이후 기상청 산식
- 겨울철(10~익년 4월): 기온 10℃ 이하이면서 풍속 1.3m/s 이상일 때 기상청 풍속냉각 산식
- 위 조건에 해당하지 않거나 필요한 값이 없을 때: 기온을 소수점 첫째 자리로 반환

서버와 앱 직접조회가 같은 입력에 같은 값을 내도록 동일 산식을 각각 구현하고 회귀 테스트를 둔다. 기상청 페이지의 값은 관측 기반이고 앱은 단기예보 입력으로 계산하므로 기상청 관측 화면과 시점별 차이가 생길 수 있다.

### Main 문구: 한국인 PT 감각 + 기상청 위험값

[Kang et al. (2022)](https://pubmed.ncbi.nlm.nih.gov/35244763/)의 한국인 PT 연구는 `20/28/36/43℃`를 감각 경계로 제시한다. 다만 PT와 기상청 체감온도는 서로 다른 지수이고 현재 예보에는 정확한 PT 계산에 필요한 복사환경 등이 없으므로, `20/28℃`는 한국인 감각 문구의 임시 경계로만 사용한다.

33℃부터는 사용자가 즉시 위험 신호를 인지하도록 [기상청 폭염특보 기준](https://www.weather.go.kr/w/forecast/guide/standard.do)의 `33/35/38℃` 값을 우선한다. 화면의 한 시점 값만으로 공식 주의보·경보 발효를 뜻하지 않으므로 `폭염주의보`, `폭염경보`라는 특보 명칭은 쓰지 않는다.

| 기상청 방식으로 계산한 체감값 | Main 문구 | 근거와 의미 |
| --- | --- | --- |
| 38℃ 이상 | 위험한 더위 | 기상청 중대 위험값을 즉시 드러내는 행동 문구 |
| 35~37.9℃ | 더위 경계 | 기상청 경보 기준값에 대응하되 공식 특보와 구분 |
| 33~34.9℃ | 더위 주의 | 기상청 주의보 기준값에 대응하되 공식 특보와 구분 |
| 28~32.9℃ | 더움 | 한국인 PT `Warm` 경계와 한국어 여름 표현을 반영 |
| 20~27.9℃ | 조금 더움 | 한국인 PT `Slightly warm` 구간을 반영 |
| 10~19.9℃ | 선선한 편 | 고온 PT 연구 범위 밖의 중립 UI 문구 |
| 0~9.9℃ | 쌀쌀한 편 | 고온 PT 연구 범위 밖의 중립 UI 문구 |
| 0℃ 미만 | 추운 날씨 | 고온 PT 연구 범위 밖의 중립 UI 문구 |

따라서 체감값 31.4℃는 기존 `따뜻한 햇살`이 아니라 `더움`으로 표시한다.

### 더위 임계값의 코드 역할

서로 다른 목적의 숫자가 같은 "더위 기준"으로 오해되지 않도록 역할명을 분리한다.

| 값 | 코드 역할명 | 적용 출력 |
| --- | --- | --- |
| 28℃ | `HEAT_SENSATION_SCENE_THRESHOLD` | 브리핑의 그늘·휴식 장면 선택과 Main의 감각 표현 |
| 33℃ | `actionAirTemperature`, `actionApparentTemperature` | 물·양산 등 사전 준비 행동을 만드는 날씨 Fact |
| 35℃ | `immediateActionApparentTemperature` | 지속 구간을 기다리지 않는 즉시 행동 Fact |
| 38℃ | `heatDangerThreshold` | Main에서 위험한 더위 표현 |
| 31℃ 미만 | `releaseApparentTemperature` | 더위 지속 구간의 해제 경계 |

이 이름은 현재 출력 경로의 역할을 명시한 것이며, 각 숫자의 최종 채택 근거는 별도의 수치 기준 근거자료 선정 작업에서 다시 검토한다.

## 2. 한국인 대상 추가 근거

### 야외 현장 교차검증

[Shin et al. (2025)](https://www.jeri.or.kr/articles/article/EwXe/)은 서울·수원에서 6회 야외 설문과 미기상 관측을 수행했다. 한국형 PT는 주관한서감과 가장 높은 설명력(R² 0.991), 기상청 폭염체감온도는 온열쾌적감과 가장 높은 설명력(R² 0.986)을 보였다. 이 결과를 근거로 PT는 감각 문구, 기상청 체감온도는 계산값과 위험 안내에 사용하는 역할 분리를 채택했다.

### 지역 순응 차이

[서울·대구 성인 남성 각 200명 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002322756)는 대구 거주자의 야외 덥고 춥다고 느끼는 경계가 서울보다 약 1℃ 높고 더위 내성이 높다고 보고했다. 전국 공통 문구는 유지하되, 향후 장기 사용 지역이나 기후권을 개인화 입력으로 고려할 근거다.

### 연령·공간 차이

[수원 시민과학 야외 열쾌적 연구](https://pubmed.ncbi.nlm.nih.gov/39524703/)는 32℃를 넘을 때 공간 유형별 온열감 차이가 커졌고, 19~30세의 주관한서감이 가장 높으며 41세 이상에서는 보고된 열 민감도가 낮아지는 경향을 확인했다. 덜 덥다고 보고하는 것이 생리적 위험이 낮다는 뜻은 아니므로 고령층에는 문구 완화가 아니라 별도 보호 강화를 검토해야 한다.

[국내 농촌 고령자 104명 연구](https://pubmed.ncbi.nlm.nih.gov/33434424/)와 [국내 7대 도시 의료 빅데이터 연구](https://pubmed.ncbi.nlm.nih.gov/39433792/)도 고령층의 폭염 건강 취약성을 뒷받침한다. 향후 나이·취약 설정은 체감 문구보다 수분, 휴식, 야외활동 제한 추천의 우선순위와 강도에 반영하는 편이 안전하다.

### 건강 결과 기준

[서울 지역 온열질환 연구](https://pubmed.ncbi.nlm.nih.gov/42016480/)는 체감온도 36℃를 넘으며 온열질환 위험이 급격히 증가하는 비선형 패턴을 보고했다. 이는 공식 특보 기준을 대체하지 않지만, 35℃ 이상에서 행동 권고를 강화하고 취약계층에는 더 보수적으로 안내할 후속 근거다.

### 실내 쾌적 기준

[서울 사무실 213명 현장 연구](https://kiss.kstudy.com/DetailOa/Ar?key=53387402)는 SET* 중립값 25.3℃, 쾌적 범위 23.8~26.8℃를 제시했다. 이는 냉방된 실내·SET* 기준이므로 야외 Main 체감값 구간에는 적용하지 않고, 향후 실내 냉방 가이드 기능의 후보 근거로만 보관한다.

## 3. 적용 한계와 후속 기준

- 현재 Main의 `20/28℃` 감각 경계는 PT 값을 직접 계산한 결과가 아니라 기상청 체감값에 적용한 프록시다.
- 정확한 PT 또는 UTCI를 추가하려면 평균복사온도/일사, 풍속 기준 높이, 활동량, 의복량 등 추가 입력과 검증이 필요하다.
- 공식 폭염특보는 한 시점 값만이 아니라 일 최고값과 지속일수 조건을 사용한다. 앱의 `더위 주의/경계`는 특보 발효 상태가 아니라 현재값 기반 행동 신호다.
- 다음 개인화 우선순위는 `고령·건강취약`, `야외활동/근로`, `그늘·도심 공간`, `거주 지역 순응` 순으로 검토한다.
- 한국인 표본으로 검증된 야외 한랭 감각 구간은 현재 근거가 충분하지 않아 임의의 세부 임계값을 추가하지 않는다. 겨울 숫자는 기상청 풍속냉각 산식을 유지한다.
