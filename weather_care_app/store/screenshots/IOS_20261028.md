## 소개 순서

1. 지금 날씨·오늘 최저/최고·어제 비교
2. **지역별 알림**: 실제 구역 선택 메뉴의 저장 지역과 알림 ON/OFF. 기존 시간별 타임라인 이미지를 교체한다.
3. 실제 소형·중형·대형 홈 위젯
4. 실제 다크 Main 화면과 다크 대형 홈 위젯
5. 준비물 요약·현재 비·기상특보·낙뢰·자외선의 알림 예시 카드
6. 심화 날씨의 실제 관측 자료
7. 최신 일주일 예보
8. 실제 항목별 알림 설정

5번은 기능 소개용 예시 카드이며 실제 푸시 수신 화면이 아니다. 그 밖의 앱·위젯은 시뮬레이터에서 직접 촬영한다. iPad 등록 이미지는 동일한 iPhone 앱·위젯 촬영본을 비율 유지해 배치한 소개 이미지이며 iPad 직접 촬영본으로 설명하지 않는다.

## 촬영과 제작 기준

Flutter 3.47.4의 일반 `lib/main.dart`로 빌드한다. 최신 Debug 동작에 따라 스토어 버전 검사를 생략하고 제품 UI와 실제 서버 조회를 사용한다. Main·지역 메뉴·일주일 예보·설정·위젯은 운영 서버, 심화 날씨는 기존 제작 기준대로 시험 서버의 실제 관측 자료를 사용한다. 촬영용 시뮬레이터의 지역과 테마는 실제 앱 UI에서 설정한다. 사용자 실기기·기존 실행 중인 시뮬레이터의 설정은 변경하지 않는다.

앱 원본은 1290×2796이며 상태바 177px와 홈 표시 영역 102px만 제외한다. 1290×2517의 나머지 화면과 하단 탭 메뉴를 보존한다. 최종 이미지에서는 비율 유지 축소·배치와 바깥 그림자만 적용한다. 실제 위젯은 홈 화면에서 촬영하고 위젯 영역 밖의 배경만 제거하며 내부 불투명 픽셀 보존을 검사한다.

원본 PNG·접근성 트리·명령 기록·빌드/XCTest 로그는 ignored `build/ios-live-store-20261028/`에 보관한다. 배포용 원본 폴더에는 원본 해시와 크롭 좌표를 기록한다. Android 제작과 충돌하지 않도록 Android 이미지·도구·공용 통합 ZIP은 갱신하지 않는다. 서버 배포·실제 푸시 발송·스토어 제출은 수행하지 않는다.

## 다시 만들기

실제 촬영은 [촬영 도구 안내](../native_ios_app_capture/README.md)를 따른다. 앱 원본을 내보낼 때 `export_capture.py --date 20261028`을 사용한다. 촬영본에서 등록 이미지만 재생성하려면 앱 루트에서 실행한다.

```sh

```
