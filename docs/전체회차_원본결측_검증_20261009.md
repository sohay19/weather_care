# 전체 보관 회차의 원본 결측 확인

검사 시각: 2026-10-09 10:07 KST. 최신 회차 표본 대신 운영 SQLite에 보관된 실황 122개와 예보 2,123개 파일 전부를 하나의 읽기 전용 트랜잭션에서 검사했다. API 추가 호출, 런타임 변경, 배포는 하지 않았다.

## 풍향 8파일은 모든 일시에 없는가

**아니다. 일반 예보 구간의 풍향 파일 218개는 존재한다. 반면 마지막 연장 구간은 전일 17시와 당일 05시 발표 모두 8개씩 계속 누락되어 있다.** 이 8개는 풍속 WSD가 아니라 풍향 VEC다.

나머지 필수 8개 변수 파일이 전부 있는 발표·유효시각을 기준으로 비교했다. 수집하지 않은 회차나 요청 전 예산 차단을 원본 미제공으로 판정하지 않았다.

| 발표 시각(KST) | 일반 구간 풍향 파일 | 마지막 연장 구간 풍향 파일 |
|---|---:|---:|
| 10/8 17:00 | 79/79 정상 저장 | 0/8 |
| 10/8 23:00 | 24/24 정상 저장 | 검사 대상 없음 |
| 10/9 02:00 | 24/24 정상 저장 | 검사 대상 없음 |
| 10/9 05:00 | 67/67 정상 저장 | 0/8 |
| 10/9 08:00 | 24/24 정상 저장 | 검사 대상 없음 |
| 합계 | 218/218 | 0/16 |

누락된 유효시각은 두 발표 모두 **10/12 03·06·09·12·15·18·21시, 10/13 00시**다. 바로 앞 10/12 00시는 두 발표 모두 풍향 파일이 있다. 같은 연장 시각의 풍속 파일도 모두 있다. 저장된 풍향 파일 218개에서는 조사 대상 302격자 전부 풍향 값이 유효했다.

전체 보관 scheduler/prewarm 로그 대조에서도 같은 16개 파일의 반복 실패를 확인했다. 10/8 17시 연장 구간은 합계 256회(UNKNOWN 245, TIMEOUT 10, NETWORK_ERROR 1), 10/9 05시 연장 구간은 223회(UNKNOWN 183, TIMEOUT 10, NO_USABLE_DATA 30) 실패했다. UNKNOWN은 빈 본문을 별도 분류하기 전 기록이므로 전부 0바이트라고 단정하지 않는다. 앞선 직접 호출에서는 동일 연장 구간의 HTTP 200·0바이트를 확인했다.

일반 구간에도 일시적인 실패가 있었다. 10/9 02시 발표의 10/9 23시 풍향은 TIMEOUT 1회, 05시 발표의 10/9 12시 풍향은 NETWORK_ERROR 1회 기록이 있지만 **두 파일 모두 이후 정상 저장되어 있다**. 요청 전 BUDGET_EXHAUSTED는 공급자가 데이터가 없다는 증거가 아니다.

따라서 확인된 패턴은 모든 풍향 데이터의 부재가 아니라 **연장 마지막 날의 전국 풍향 파일이 반복해서 제공되지 않는 문제**다. 발표별 제공 범위 조건이나 파일 생성·게시 문제를 의심할 근거가 있지만 기상청 내부 코드·로그를 보지 못했으므로 구체적인 내부 결함은 확정하지 않는다. 이전 공식 지점예보 검사에서는 같은 8시각 풍향이 정상 반환되었다.

## 302격자의 값은 모든 보관 시각에 없는가

실황 조사 기간은 **10/7 23:50~10/9 09:50 KST**, 보관된 122회차 전부다. 조사 대상은 앞선 09:20 원본에서 결측이었던 고정 302격자로 유지했다.

| 실황 항목 | 저장 파일 수 | 전 파일에서 결측인 격자 | 결과 |
|---|---:|---:|---|
| 기온 T1H | 122 | 302 | 283격자는 항상 -99, 19격자는 항상 -999 |
| 습도 REH | 122 | 302 | 동일 |
| 풍속 WSD | 122 | 302 | 동일 |
| 풍향 VEC | 61 | 302 | 파일이 있는 모든 회차에서도 결측 |
| 1시간 강수량 RN1 | 60 | 302 | 파일이 있는 모든 회차에서도 결측 |
| 강수형태 PTY | 61 | 283 | 나머지 19격자는 모든 저장 파일에서 유효 |

기온·습도·풍속은 302격자 중 한 곳도 보관 기간 안에서 정상 값으로 바뀐 적이 없다. 따라서 조사 기간에서는 갱신 지연에 따른 일시 결측으로 보기 어렵다. 선택 항목의 파일이 없는 회차와 파일 안의 결측 값을 구분해서 집계했다.

예보는 **6개 발표 회차(10/8 02·17·23시, 10/9 02·05·08시)**의 보관 파일 전체를 검사했다. 10/8 02시는 최저·최고기온 파일만 있어 풍향 비교 대상에 포함하지 않았다. 예보 유효시각 범위는 **10/8 06시~10/13 00시**다.

| 예보 항목 | 저장 파일 수 | 전 파일에서 결측인 격자 | 나머지 격자 |
|---|---:|---:|---|
| 기온 TMP·습도 REH·강수확률 POP·강수량 PCP·적설 SNO | 각 234 | 동일한 283 | 19격자는 234파일 모두 유효 |
| 최저기온 TMN | 16 | 283 | 19격자는 15파일 유효, 1파일 결측 |
| 최고기온 TMX | 17 | 283 | 19격자는 17파일 모두 유효 |
| 풍속 WSD·하늘상태 SKY·강수형태 PTY | 각 234 | 0 | 302격자 모두 모든 저장 파일에서 유효 |
| 풍향 VEC | 218 | 0 | 파일이 있는 구간에서는 302격자 모두 유효 |

**302격자의 모든 항목이 모든 시각에 없는 것은 아니다.** 실황 기온·습도·풍속은 지속 결측이고, 전국 예보 기온·습도 등은 283격자에서 지속 결측이다. 같은 격자의 예보 풍속·하늘상태 등은 정상이다. 제공 항목에 따른 공간 마스킹 차이를 의심할 패턴이며, 내부 마스킹 정책은 공급자 확인이 필요하다.

## 검증 범위와 제한

- 보관 원본 전체를 검사했으나 과거 모든 날짜의 제공처 아카이브를 조회한 것은 아니다.
- 실황 기간의 가능한 10분 시각은 205개이며 122개가 보관되어 있다. 나머지 83시각은 이 검사로 값의 존재 여부를 판단하지 않는다.
- 예보 역시 운영 수집 계획에 따라 저장된 발표·유효시각만 검사했다. 중간 발표의 연장 구간을 조회하지 않았다는 사실을 데이터 부재로 해석하지 않는다.
- 시간만 더 기다리면 해결된다고 보거나 영구적으로 제공되지 않는다고 단정하지 않는다. 현재 증거는 위 보관 기간에서 반복되는 항목·구간별 결측이다.
