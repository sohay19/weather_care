## 2번 촬영 기준

일반 `lib/main.dart`를 Flutter 3.47.4로 빌드해 기존 촬영 전용 iPhone 15 Pro Max / iOS 17.5 시뮬레이터(71087354-633A-42B1-AD48-60A603FE411F)에 설치했다. 운영 서버의 실제 자료를 사용하고 XCTest로 제품 앱의 지역 선택·알림 스위치를 조작했다. Simulator 창을 열지 않아 사용자 작업 화면을 방해하지 않았다.

전체 캡처 1290×2796에서 상태바 177px와 홈 표시 영역 102px만 제외한다. 앱 안의 문구·수치·스위치를 합성하거나 수정하지 않고 원본 비율을 유지해 배치한다. iPad 등록 이미지도 같은 iPhone 촬영본을 사용하며 iPad에서 별도로 촬영한 화면은 아니다.

크롭과 해시는 `source-ios-20261103/phone/`에 보관한다. 전체 캡처·접근성 트리·촬영 명령·빌드/XCTest 로그·기존 이미지 비교 결과는 ignored `build/ios-region-screenshot-20261103/`에 보관한다. 2번 교체 당시에는 다른 14장을 유지했고, 후속 요청에서 5번만 추가로 교체했다.

## 5번 Apple Watch 촬영 기준

실제 설치된 `com.codesoha.weathercare.watchkitapp` 제품 앱을 전용 Apple Watch Series 10 42mm / watchOS 11.5 시뮬레이터에서 실행했다. 연결된 전용 iPhone 16 Pro / iOS 18.6에서 실제 서버 날씨를 받아 표시한다. 실물 Apple Watch 촬영본은 아니며 HTML 시안·생성형 화면·시험 날씨 주입은 사용하지 않았다.

XCTest의 `XCUIScreen.main.screenshot()`으로 네 페이지를 직접 촬영했다. 374×446 전체 화면의 시스템 시계·페이지 표시기·문구·날씨 수치를 보존하고 원본 비율로 확대해 배치했다. 사각 화면의 검정 모서리에 둥근 마스크와 바깥 테두리를 적용했으며 내부 UI는 재구성하지 않았다. 두 등록 규격에 같은 워치 촬영본을 사용한다.

- 원본: `source-watchos-20261103/current.png`, `prep.png`, `timeline.png`, `life.png`
- 기기·원본 해시·시각·촬영 기준: `source-watchos-20261103/capture-manifest.json`
- 전체 촬영 명령·접근성 트리·XCTest 로그·검증 결과: ignored `build/watch-store-screenshot-20261103/`
- 기존 `05-notifications.png`는 등록 폴더와 최신 ZIP에서 `05-watch.png`로 대체했다. 과거 날짜 ZIP과 Android 이미지는 보존했다.

이번 5번 교체 전과 비교해 다른 iPhone·iPad 14장은 그대로다. 사용자 데스크톱/창을 전환하지 않고 전용 기기만 백그라운드에서 조작했다. 제품 코드 변경·App Store Connect 업로드는 수행하지 않았다.
