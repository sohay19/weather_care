## 관찰 사항과 복구

- 기존 지점예보 수집의 `weather_collection_failed / point_forecast / UNKNOWN`은 배포 전 2시간 구간에서 11건, 배포 후 14:10에도 1건 관찰됐다. 해당 수집 소스는 이번에 변경하지 않았으며 같은 종류의 오류가 배포 전부터 반복됐다. 원인은 이번 작업에서 확정하거나 수정하지 않았다. 검증한 기존 앱 조회·설정 저장은 통과했으며 이 오류가 해소됐다고 보고하지 않는다.
- 최초 배포 검사 도구가 `/health`의 정상 텍스트 `ok`를 JSON으로 읽어 변경 전에 중단됐다. 텍스트 응답 검사로 고친 뒤 DB·서비스 변경을 진행했다. 구 앱 검사에서도 임시 설치 삭제 후 HTTP410을 정상 결과로 처리하도록 검증 코드를 정정하고 인증·설정 2개 검사만 다시 실행해 통과했다. 제품 소스 변경이나 배포 후 원복은 없었다.
- 배포 잠금, 적용 직전 소스·스키마 대조, SQLite 온라인 백업·트랜잭션, 기존 소유권·권한을 유지하는 원자 파일 교체와 복구 절차를 사용했다. 필요 시 백업의 기존 파일을 복원하고 신규 모듈을 제거한 뒤 API·스케줄러를 재시작한다. 추가 열은 이전 코드와 호환되므로 이후 사용자 변경을 잃지 않도록 사용자 DB 전체를 과거 백업으로 덮어쓰지 않는다.
