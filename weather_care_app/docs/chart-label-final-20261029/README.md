# 막대 위 수치 유지와 신적설 하한 점 표시

후속 요청으로 신적설 하한 점 사이의 시간 연결선을 복원했다. 최신 결과는 [신적설 연결 예시](../chart-snow-connected-20261029/README.md)에 있으며 이 폴더는 직전 결과를 보존한다.

- 확률 수치는 기본적으로 기존처럼 막대 바로 위에 표시한다. 해당 위치가 선·점·다른 수치와 겹치면 자기 막대 내부의 빈 공간을 찾는다. 막대 안의 글자 대비와 충돌 방지는 유지한다.
- 1번 예시의 앞 세 60%는 기존 위치인 막대 위를 유지하고, 마지막 60%만 급경사 선과의 충돌을 피해 막대 안으로 옮긴다.
- 상한 없는 신적설 `2cm 이상`은 2cm 높이의 점만 표시한다. 위쪽으로 뻗는 범위 선·범위 띠·끝 막대 및 양옆 시각과의 연결선을 그리지 않는다. `2cm 이상`이라는 원본 의미와 문구는 보존하며 정확히 2cm로 바꾸지 않는다. 상한이 있는 범위 예보 표시는 유지한다.
- 지난 시각에는 관측 적설량만, 앞으로 시작하는 구간에는 신적설·확률 예보를 표시하는 기존 시간 구분을 유지한다.

실제 수정된 Flutter 위젯과 SUITE 글꼴로 검사 자료를 비표시 렌더링한 PNG다. 실기기 촬영이나 운영 날씨 자료가 아니다. 요청한 결과는 `01-rain-peaks.png`, `03-snow-ranges.png`이며 나머지 세 예시도 함께 재생성했다. 이전 폴더의 이미지는 보존했다.
