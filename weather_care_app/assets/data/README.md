# 전국 지역 선택 목록

`kma_regions.json`은 기상청 날씨누리의 행정동 선택 목록을 앱에서 읽는 데이터다.

- 출처: [기상청 날씨누리](https://www.weather.go.kr/w/index.do)
- 공개 목록: `https://www.weather.go.kr/w/rest/zone/dong.do`
- 실제 요청 계약: [날씨누리 dong-config.js](https://www.weather.go.kr/w/resources/js/app-2021/dong-config.js)
- 확인일: 2026-09-10 (정확한 수집 완료 시각은 JSON `retrievedAt`)
- 3,838행: 시·도 16, 시·군·구 257, 읍·면·동 등 하위 지역 3,565. 원본의 현행 명칭을 그대로 사용하며 과거 시·도 수로 보정하지 않는다.
- 열: 기상청 지역 코드, 상위 코드, 지역 이름, 예보 격자 X, Y. 이름·격자는 원본 값이고 대표 위경도를 사용자 위치로 사용하지 않는다.
- 이 목록의 격자는 [단기예보의 지역 대표 예보 격자](https://www.data.go.kr/data/15084084/openapi.do)다. 행정구역 전체 또는 500m 분석의 정확한 사용자 위치를 뜻하지 않는다.

기상청 원본은 코드 `2815555000`을 인천 영종구 용유동(50,124)과 운서2동(52,125)에 중복 사용한다. 코드를 임의 수정하거나 한 행을 삭제하지 않는다. 앱 선택 키는 `코드|이름|X|Y`로 구분한다. 상위 코드·이름으로 전체 지역명을 구성하며 세종의 연속된 같은 상위 이름만 중복 표시하지 않는다.

갱신은 저장소 루트에서 PowerShell 7로 `./scripts/update_region_catalog.ps1`을 실행한다. 인증키를 사용하지 않고 공개 목록을 순서대로 확인한다. 전체 수집·검증 후에만 생성 파일을 교체한다. 변경된 계층·코드 충돌·격자와 테스트의 스냅샷 수를 검토하고 앱 업데이트로 배포한다. 런타임에서 기상청 웹 검색을 호출하지 않는다.

선택한 키가 새 목록에서 사라지거나 격자가 바뀌면 이전 격자로 조용히 대체하지 않고 다시 선택하도록 한다. GPS 모드로 바꿔도 마지막 수동 선택은 기기에 보존한다. 이 키는 서버 설정 API에는 전송하지 않으며 기존 `currentRegion: nx_ny` 계약을 유지한다.
