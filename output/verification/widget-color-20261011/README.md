# Android 위젯 컬러·기준시간 배치 캡처

- 2026-10-11 Android API 36 에뮬레이터에서 최종 디버그 APK 설치 후 직접 촬영.
- 하남시 감북동 수동 지역 설정, 실제 서버 응답 사용. 앱 데이터·위젯 비트맵을 임의 생성하거나 재색칠하지 않음.
- `main-dark.png`: 앱 Main 화면.
- `widget-small-dark.png`, `widget-medium-dark.png`, `widget-large-dark.png`: 런처에서 크기를 변경하며 촬영한 원본 전체 화면.
- `widget-small-crop.png`, `widget-medium-crop.png`, `widget-large-crop.png`: 위젯 영역만 잘라낸 비교용 이미지.
- 소형은 지역명 아래 기준시간, 중형·대형은 새로고침 버튼 왼쪽 기준시간. 현재 날씨 아이콘의 원래 컬러 유지.
- 스토어 9번은 앱 Main과 대형 위젯 원본을 함께 사용.
