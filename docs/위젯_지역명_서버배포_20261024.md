## 변경 내용

위젯 요청에 지역명이 없을 때 내부 오늘 날씨 조회가 이미 확인한 지역명을 최종 위젯 응답에 전달한다. 배포 전 실제 GPS 및 행정코드 요청은 오늘 응답의 `서울특별시 종로구 청운효자동`을 위젯 응답에서 `현재 위치`로 잃고 있었다. 배포 후 두 요청 모두 `종로구 청운효자동`을 표시한다.

구형 Android·iPhone 위젯의 정상 이름 보존과 호환되도록 끝내 이름을 확인하지 못한 서버 응답의 대체값은 `현재 위치`로 유지한다. 새 앱은 이를 조회 중·최종 실패 상태로 변환하고 최대 5회 더 조회한다. 새 문구와 재시도 전체 적용에는 앱 업데이트가 필요하다.

- 실행 소스를 해시로 대조하고 후보 TypeScript 문법 검사를 수행했다. 시험 API에 먼저 적용하고 확인한 뒤 운영 API를 적용했다. 기존 캐시가 정상임을 먼저 확인하고 API만 재시작했다. 전체 선수집이나 스케줄러 재시작은 수행하지 않았다.
