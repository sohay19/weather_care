# 개인정보처리방침 연결 준비 점검

확인일: 2026-09-10

이 문서는 내부 준비 점검표다. 정식 개인정보처리방침이나 공개용 초안이 아니며, 법적 준수 완료를 의미하지 않는다. 운영자가 확인하지 않은 이름·연락처·보유기간을 넣어 배포하지 않는다.

## 코드에서 확인한 현재 상태

| 항목 | 확인 내용 | 근거 |
| --- | --- | --- |
| 기능 안내 | Setting의 데이터·권한 안내는 개인정보처리방침을 대신하지 않는다고 명시 | `weather_care_app/lib/features/settings/settings_guide.dart` |
| 서버 등록 | 설치 식별자, FCM 토큰, 격자, 위치 모드, 플랫폼, 앱 버전, 시간대 및 조건부 좌표를 등록·저장하는 구조 | `weather_care_server/src/api/installations.ts`, `src/database/installationsRepository.ts` |
| 설정·발송 이력 | 알림 설정, 중복 발송 확인 이력, 특보/도로/강수 관련 발송 상태 저장 | 서버 migrations, `src/notification/notificationScheduler.ts` |
| 삭제·보유 | 사용자 정보 삭제 UI/API와 정해진 보유기간에 따른 사용자 데이터 정리 경로는 확인되지 않음. 특보 상태 행 삭제를 개인정보 전체 삭제로 설명하면 안 됨 | 등록 API 및 스케줄러 검색, 기존 데이터 안내 |
| SDK | Firebase/FCM 초기화, Firebase Analytics 의존성 포함, Google Mobile Ads 초기화 | 앱 `pubspec.yaml`, `lib/main.dart` |
| 미확인 사항 | SDK·광고 운영 콘솔, 실제 수집/동의 설정, 외부 서비스의 보관·처리 지역·계약 조건 | 코드만으로 확정할 수 없음 |

상세 데이터 흐름은 [기존 데이터·권한 안내 문서](./설정_데이터_권한_안내.md)를 함께 사용한다. API 필드가 존재한다는 사실과 모든 이용자에게 해당 필드가 항상 전송된다는 주장은 구분한다.

## 순서대로 확인할 사항

1. **운영자 정보:** 개인 운영/사업자 구분, 공개할 운영자 또는 사업자명, 개인정보 문의를 실제 접수할 이메일. 저장소 이름·패키지명·도구 로그인 계정으로 추정하지 않는다.
2. **보유·삭제:** 정보 종류별 이용 목적과 필요한 기간, 이용 종료/삭제 요청 처리 방법, 백업·로그 처리. 아직 없는 자동 삭제 기능이나 처리 기한을 약속하지 않는다. 기간을 결정한 뒤 필요한 구현 범위를 별도 확인한다.
3. **외부 처리·SDK:** Cloudflare·Firebase·Google 광고 서비스의 실제 설정 및 역할, 동의 흐름, 대상 연령, 이전되는 항목·국가·기간 등의 적용 사항을 확인한다. 서비스 이름만으로 법적 역할이나 국가를 단정하지 않는다.
4. **공개와 앱 연결:** 기존 공개 URL이 있는지 확인한다. 없으면 본문 검토가 끝난 뒤 접근 가능한 공개 페이지와 Setting 진입점을 구현한다. 빈 페이지, 가짜 URL, 미완성 문서는 정식 방침으로 노출하지 않는다.

운영자명·이메일 확인만으로 2~4번이 자동 확정되는 것은 아니다. 실제 코드/콘솔·운영 절차와 문구가 일치해야 한다.

## 공개 전 확인 기준

- Google Play 정책은 앱 내 개인정보처리방침 링크 또는 본문, Play Console의 방침 링크, 개발자·문의 경로 및 보관·삭제 정책 등을 요구한다. 공개 URL은 로그인 없이 접근 가능하고 PDF가 아닌 형태로 준비한다. 계정 삭제 관련 요건은 앱의 실제 계정 생성 기능에 따라 적용을 검토하며, 설치 식별자를 회원 계정으로 단정하지 않는다. [Google Play 사용자 데이터 정책](https://support.google.com/googleplay/android-developer/answer/10144311?hl=ko)
- 국내 작성 참고자료로 개인정보 포털 목록에 `2026 개인정보 처리방침 작성지침`(2026-04-24 게시)이 확인된다. 이번에는 목록의 발간 정보만 확인했으며 첨부 전문 검토를 마친 것은 아니다. 본문 작성 시 최신 지침 전문과 실제 적용 법령을 확인한다. [개인정보 포털 지침 자료실](https://www.privacy.go.kr/front/bbs/bbsList.do?bbsNo=BBSMSTR_000000000049)

이번 작업에서는 운영자 확인이 필요한 단계에서 멈췄다. 앱/서버 코드, 수집 설정, 저장 정보, 운영 배포는 변경하지 않았다.
