### 광고 포함 여부

현재 Release 코드는 유효한 운영 광고 단위 ID를 기본값으로 사용하므로 `광고 포함`으로 준비한다. Today·Main·Advanced·Week의 네이티브 광고와 앱 오프닝 광고가 있으며, UMP가 광고 요청을 허용한 뒤 요청한다. 광고 제거 구매 권한이 있으면 광고를 요청하지 않는다.

제출 전 다음 항목을 현재 빌드와 일치시킨다.

1. Play Console의 광고 선언을 `광고 포함`으로 변경
2. 개인정보처리방침의 광고 처리 항목 개정·게시

백그라운드 위치 시험은 GPS 모드·전체 알림·서버 사용을 켜고 위치를 항상 허용한 뒤 이동한 지역의 알림 지역과 홈 위젯 갱신을 확인해 주세요. iOS는 큰 위치 변화 감지를 사용하며 추가 권한 팝업과 실제 갱신 시점은 운영체제가 결정합니다. 기능을 끄거나 수동 지역을 선택하면 감시를 중지합니다. 이동 경로 이력은 저장하지 않습니다.

GPS 모드의 홈 위젯은 위젯 위치 사용을 별도로 요청할 수 있습니다. 위젯의 위치 사용을 허용한 뒤 새로고침 버튼을 눌러 날씨를 갱신할 수 있고, 수동 지역 모드는 저장한 지역으로 갱신합니다.

앱에는 광고와 선택형 1회 구매 광고 제거가 있습니다. 광고는 UMP가 요청을 허용한 경우에만 로드합니다. Setting → 광고 제거에서 상품과 구매 내역 복원을 확인할 수 있습니다. ATT 권한은 요청하지 않습니다.

Setting → 데이터 권한 안내에서 개인정보처리방침, 서버 내 나의 데이터 삭제, 이용 통계 동의·철회와 삭제 요청 경로를 확인할 수 있습니다. Setting → 데이터 저장·기기 권한 상태에서 저장 상태와 OS 권한을 확인할 수 있습니다.

날씨 데이터는 대한민국 지역을 기준으로 제공됩니다. 심사 중 서버 연결 문제가 있으면 화면을 아래로 당겨 다시 시도해 주세요.

| 권한·기능 | 사용자 안내 |

| iOS 원격 알림 백그라운드 모드 | FCM 푸시 처리에 사용 |
| 광고 식별자 | Android 광고 ID·Ad Services 광고 ID 권한 포함, iOS ATT 요청 없음. 실제 광고 SDK 처리에 맞춰 개인정보 공개 |

첫 실행의 통합 안내에서 `동의하고 계속`을 고르면 알림 → 사용 중 위치 → 백그라운드 위치 순서로 요청하고 `백그라운드 제외`를 고르면 일반 권한만 요청한다. Android 11 이상은 별도 권한·설정 화면에서 항상 허용이 필요하며 iOS의 추가 항상 허용 요청 시점은 운영체제가 결정한다. 설정의 `데이터 저장·기기 권한 상태`에서 상태와 백그라운드 기능을 관리한다.

iOS는 `location`·`remote-notification`·`fetch` 백그라운드 모드가 선언돼 있고 이동 감지에는 큰 위치 변화 감지를 사용한다. GPS 모드 홈 위젯은 위치 사용을 별도로 요청할 수 있으며 새로고침 버튼에서 현재 위치를 측정한다. 수동 지역 위젯은 저장한 지역을 사용한다. 위치 갱신 주기나 강제 종료 뒤 동작을 보장하지 않는다.

App Store Connect의 **앱 개인정보 보호** 답변과 공개 개인정보처리방침에 위젯이 GPS 새로고침 시 서버로 전송하는 위치의 실제 정밀도·보관 방식을 반영한다. **앱 심사 정보 → 메모**에는 첫 실행 권한 안내, 위젯의 별도 위치 허용, GPS 모드에서 위젯 새로고침 버튼을 누르는 검증 절차를 적는다.

권한 거부 시 영향:

- 위치 거부: 현재 위치 자동 확인과 정밀 강수·도로 안내는 제한되지만 Main에서 수동 지역 선택 가능
- 항상 위치 거부 또는 백그라운드 제외: 이동에 따른 자동 알림 지역·위젯 갱신 제한. 수동 지역 조회 가능
- 알림 거부: 푸시 알림은 받을 수 없지만 앱을 열어 날씨 확인 가능
- Analytics 거부: 날씨와 알림 핵심 기능 제한 없음
