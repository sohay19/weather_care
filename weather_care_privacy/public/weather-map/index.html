WEATHER FORECAST GRID

'날씨챙겨' 예보 구역 지도

날씨챙겨는 기상청 단기예보의 5km 격자 nx·ny를 기본 판단 단위로 사용합니다. 같은 칸을 선택하면 같은 중앙 수집 예보를 사용합니다.

WHAT THE GRID MEANS

격자 별 공유/비공유 항목

공유 항목

  • 현재 기온·습도·바람 등 초단기 관측
  • 시간별·주간 기온, 하늘 상태, 강수, 습도, 풍향·풍속
  • 자외선지수와 대기질
  • 관측소 기반 가시거리와 기상특보
  • 공통 자료로 만든 날씨 브리핑과 생활 안내
  • 사용자 설정이 같을 때의 준비물 추천과 타임라인

비공유 항목

  • GPS 좌표 기준 실시간 레이더 강수
  • 도로 결빙 위험과 도로 통제 정보
  • GPS 모드의 일출·일몰 시각
  • 준비물 추천 사용 여부와 알림 설정·시각
  • 사용자가 선택한 행정지역명과 앱의 체크 기록
  • 요청 시점과 기기에 남은 캐시 상태

SELECTED GRID

격자를 선택해 주세요

지도에서 칸을 누르거나 지역명을 검색하면 같은 격자를 사용하는 지역을 보여드려요.

수동 지역 선택은 격자 중심 좌표를 사용합니다.

현재 위치는 같은 격자 안에서도 실제 좌표를 함께 사용하므로 정밀 강수·도로·일출·일몰 정보가 달라질 수 있습니다.

자료 기준

행정지역명·도로·지형은 네이버 Web Dynamic Map을 사용하고, 기상청 날씨누리 행정동 검색 목록의 지역별 단기예보 격자를 그 위에 표시합니다. 격자 하나는 약 5km 간격의 예보 좌표이며 행정구역 전체의 실제 경계와 일치하지 않습니다.
