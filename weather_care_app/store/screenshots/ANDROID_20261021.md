## 제작 및 확인 기준

- 2026-10-21 작업 디렉터리의 현재 Flutter 위젯을 비표시 엔진으로 렌더링했다. 실기기·에뮬레이터 촬영으로 주장하지 않는다. 폰은 412×1000dp를 3배로, 태블릿은 800×1280dp를 2배로 각각 렌더링했다. 화면에는 현재 센서 아이콘, `심화 날씨 정보`, 통합 `만조·간조/조위`, 기준 시간과 현재값 박스를 반영했다.
- 앱 화면은 구성 요소를 새로 그린 그림이 아닌 현재 위젯의 렌더링이다. 화면 데이터는 재현 가능한 촬영용 예시이며 현재 실제 관측값이 아니다. 사용자 위치·설정·서버 자료는 변경하지 않았다. 광고 슬롯은 넣지 않았다.
- 테스트 엔진에서 준비물 자산을 미리 디코딩했다. Android 시스템의 한글 대체 글꼴을 사용할 수 없어 글꼴 미지정 부분에만 SUITE 대체 글꼴을 적용했다. 기존 지정 글꼴과 화면 색상·배치는 유지했다.
- 위젯은 현재 Android XML 구성, 주간·야간 색상 리소스, SUITE 글꼴, 공유 준비물 PNG와 네이티브 날씨 아이콘 형태를 기준으로 제작한 소개용 재현이다. 런처 캡처가 아니며 홈 화면 크기에 따른 실제 여백은 기기마다 다르다.
- 다양한 알림 이미지는 현재 발송을 지원하는 종류를 소개하는 홍보 카드다. 이미지에 `알림 예시`를 명시했다. 실제 푸시 발송·시스템 알림 패널 촬영은 하지 않았다. 특보 안내 카드의 본문은 기능 설명용 문구다.
- 그래픽 이미지는 현재 메인 화면 원본의 체크리스트와 요약 영역을 크롭해 구성했다.
- 생성형 UI, 임의 실측값, 스토어 업로드는 없다. iOS·iPad 이미지와 기존 아이콘은 변경하지 않았다.
- 모든 등록 PNG의 크기·RGB·무투명·PNG 디코딩, ZIP 무결성과 화면 렌더링 오류를 검사했다. 화면별 파일 해시는 `android-20261021-manifest.json`에 기록한다.

```powershell
& D:\flutter_3.47.4\bin\flutter.bat test --no-pub store/capture_android_test.dart
python store/generate_android_store.py
```

원본은 `source-android-20261021/phone`, `source-android-20261021/tablet`에 보관한다. 이전 Android 전용 최종 이미지는 혼동을 막기 위해 현재 폴더에서 정리했으며 변경 전 백업은 ignored `build/store-backup-20261021/`에 보관한다. 기존 iOS·iPad 자료는 이전 안내를 따른다.
