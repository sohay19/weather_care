# 전국 날씨 수집·GPS 연결·앱 표시 전체 수정사항

2026년 10월 10일 커밋 대상 작업 트리의 전체 변경을 정리한다. 마지막 중기 전환 운영 기록은 `20261010-midterm-portal`이며 12:29에 포털 중기 원본 176기온·10육상 구역을 확인했다. 근거는 [중기 전환 검증](중기예보_공공데이터_전환_검증_20261010.json)과 HANDOFF다. 이번 문서화·커밋 작업은 별도 운영 배포나 앱 설치를 수행하지 않는다. 앱 업데이트는 사용자가 진행한다.

기존 날짜별 조사·배포 문서는 당시 확인 결과를 보존한다. 최신 적설 정의와 승인 상태는 [적설 정의 정정](적설_정의_정정_및_운영_잔여이슈_20261010.md), 전체 변경의 현재 해석은 이 문서를 우선한다. 원본 결측과 모든 미래 시각의 자료 확보를 구현 완료와 혼동하지 않는다.

## 현재 운영·잔여 항목

- 10/10 11:44~11:46 점검의 필수 중앙 캐시는 197/197, 현재 육지 핵심 실황은 4,728/4,728이었다. 302개 원본 결측 격자는 인근 실황·동일 격자 지점 예보로 보충했다. 이는 모든 항목·모든 미래 회차가 항상 완비된다는 보장이 아니다.
- 2026 기준 행정 명칭·코드 보완과 2026 최신 경계 도형은 다르다. 운영 도형은 SGIS 2025Q2이며 주소정보의 2026 원본 수령·검증·교체는 남아 있다.
- 현재 적설 API는 승인·응답 검증만 완료했다. 정규 수집기·전용 8열 파서·실제 관측시각·신선도·인근 관측소·실패 캐시 보존·앱 현재 적설 계약 연결은 아직 없다. 일자료의 최심신적설을 현재 적설로 대신 표시하지 않는다.
- 앱 어제 비교 요청은 현재 `nx/ny`만 전달한다. Main/Today처럼 GPS 거리 기반 출처를 동일하게 선택하려면 비교 요청에도 좌표 전달이 필요하다. 인근 실황 요약 화면의 메타데이터 실연결과 앱 배포도 잔여다.
- 일부 대기질 지표 결측, 연장 예보의 일부 공간 결측, 과거 선택 실황 VEC·PTY·RN1 미보관은 핵심 실황 정상과 별개다. 제공처 시간초과는 간헐적 회복 사례가 있지만 공급자 내부와 네트워크 중 최종 책임은 미확정이다.
- 워치앱·꽃가루·대기정체·수도관 동파 지표는 [다음 업데이트 계획](앱_탭_구성_현황.md)에 유지한다.

## 제공처별 예상 예산의 해석

현재 문서에 남은 10/4 수치는 당시 APIHub 중기 경로를 포함한 계획이다. 이후 중기는 공공데이터포털의 별도 `DATA_GO_MID_TERM` 장부로 이동했다. 이번 검증에서 기존 계산 도구를 현재 `nationwideForecastPlan`에 다시 적용해 연장 풍향 제외를 반영하고, 중기 정상 372회·3,047,424B를 APIHub 합계에서 제외했다. 아래는 현재 경로에 맞춘 설계 추정이다. 원래 10/4·10/9 표는 당시 기록으로 보존한다.

| APIHub 계절 | 필수 호출 추정 | 필수 용량 추정 | 재시도 최대 예약 | 용량 합계 | 내부 4.5GB 대비 여유 |
|---|---:|---:|---:|---:|---:|
| 비겨울 | 3,836회 | 2.712GB | 0.400GB | 3.112GB | 1.388GB |
| 겨울 | 3,961회 | 3.768GB | 0.400GB | 4.168GB | 0.332GB |

이는 실제 계정 사용량이나 실패율이 아니라 계획 표본에 따른 추정이다. 재시도 파일 크기가 달라 호출 합계를 고정할 수 없으므로 호출 내부 상한 18,000회/일과 예약 용량 4.5GB/일을 함께 검사한다. 첫 24시간 재시도 총량은 100MB, 이후 400MB이며 용도별 예산은 원자 예약으로 보호한다. 외부 수동 호출은 서버 장부 밖에서도 제공처 계정 한도를 소비한다.

에어코리아는 사용자 지정대로 운영계정 신청 전제의 한도 문제없음으로 관리하되, 실제 429 기록은 삭제하지 않는다. ITS는 사용자 전제로 한도 문제없음이다. 공공데이터포털 지점 예보와 중기예보는 APIHub 합계에서 제외하고 각각 별도 9,000회/일 안전 장부를 사용한다. 중기는 정상 372회/일, 302격자 지점 예보는 정상 1페이지 가정 2,416회/일이며 추가 페이지·재시도는 같은 서비스 장부에 합산한다. 현재 적설의 정규 수집 호출은 아직 포함하지 않는다.

## 커밋 대상·검증
