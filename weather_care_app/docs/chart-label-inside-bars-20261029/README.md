# 막대 내부를 허용한 그래프 수치 배치

이 폴더는 꺾은선 수치만 막대 내부에 허용했던 이전 결과다. 확률 수치의 자기 막대 내부 배치와 과거 관측/미래 신적설 구분을 적용한 최신 결과는 [관측·예보 분리 예시](../chart-observed-forecast-20261029/README.md)에 있다.

사용자의 후속 요청에 따라 꺾은선 수치는 확률 막대 내부에도 배치하도록 수정했다. 선·점·범위 표시·다른 수치와의 충돌 검사는 유지한다. 확률 수치는 막대 위에 먼저 배치하고, 꺾은선 수치는 원래 점 가까이의 빈 공간에 둔다. 막대를 피하기 위해 줄였던 폭도 원래 시간 간격의 56%로 복원했다.

막대 안의 수치는 계열 색을 유지하며 글자 둘레에 대비를 보강하는 그림자를 넣었다. 불투명한 사각 배경은 사용하지 않는다. 필요한 이동에는 기존과 같은 색 점선을 사용한다.

| 예시 | 결과 |
| --- | --- |
| 01-rain-peaks.png | 1mm를 막대 안의 해당 점 바로 위에 표시하고, 0mm는 기준선 아래에 표시 |
| 02-rain-extremes.png | 6.7mm·10mm를 점 가까이 배치하고 60%·90%·100% 수치와 분리 |
| 03-snow-ranges.png | 1cm·2cm 이상을 해당 점과 범위 끝 근처에 표시하고, 두 3cm 수치는 계열 색과 위치로 구분 |
| 04-temperature-crossing.png | 기존 기온 예시와 동일 |
| 05-humidity.png | 기존 단독 습도 막대 예시와 동일 |

제품 Flutter 위젯과 SUITE 한글 글꼴을 사용해 검사용 자료를 비표시 렌더링했다. 실기기 촬영이나 운영 날씨 자료가 아니다. 앞선 결과는 ../chart-label-examples-20261029에 보존했다.

관련 7개 파일 172개 검사가 통과했고 전체 정적 분석 이슈는 없다. 추가 검사에서는 1mm 수치가 막대 안에 있고 원래 점에서 30px 이내이며 가로 중심이 일치하는지, 글자 대비 처리가 적용되는지 확인한다. 기존 1배·2배 글씨, 무작위 24시간 16종, 라이트·다크 강설, Main·Week 및 바다·하천 회귀 검사도 통과했다.

앱 폴더에서 현재 기준의 최신 예시를 재생성한다. 기본 출력은 최신 폴더다.
