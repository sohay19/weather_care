| 항목 | 상태 |

## 방침 작성 근거와 경계

- 개인정보 보호법 제30조의 처리 목적·보유기간·제3자 제공·파기·위탁·권리·담당자·자동 수집 항목을 공개 본문에 반영했다.
- Cloudflare와 Google의 수탁 업무, 이전 항목·국가·시기·방법·연락처·목적·기간·거부 방법과 영향을 공개했다. 필수 서버·FCM 처리는 계약 이행에 필요한 처리위탁·보관으로 공개하고, 선택 Analytics는 앱에서 별도 국외 이전 내용을 알린 뒤 동의받는다.
- Google Play의 공개 URL 요건에 맞춰 로그인 없이 접근 가능한 HTML 페이지를 사용하고 앱 안에 링크를 둔다.
- 이 문서와 기술 검증은 법률 자문이나 스토어 심사 승인을 대신하지 않는다. 코드·콘솔·수탁자 조건이 바뀌면 처리 전에 공개 방침과 앱 동의 문구를 함께 갱신한다.
