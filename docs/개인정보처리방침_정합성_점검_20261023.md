# 개인정보처리방침과 현재 앱·서버 동작 정합성 점검

점검일: 2026-10-23 한국 시간. 기준 커밋: `bf92211` 및 점검 당시 작업 폴더.

## 결론과 범위

공개 방침은 현재 동작과 완전히 일치하지 않는다. 광고·광고 식별자, 연령 확인, 서버 운영 방식, 운영 로그, 백업, 구매, 주소 검색·주소 변환의 **7개 영역에 수정 또는 운영 정리가 필요하다.**

공개 [개인정보처리방침](https://weather-care.pages.dev/), Flutter 앱 및 Android/iOS 설정, 미니 PC에서 실제 실행 중인 운영·시험 서버의 소스와 환경 설정, 로그 보존 상태, 백업 메타데이터를 읽기 전용으로 확인했다. Google Analytics 관리 API에서도 현재 보관 설정을 조회했다. 실사용자의 좌표·토큰·인증키·메일 내용은 조회하거나 기록하지 않았다. 과거 백업은 테이블 존재와 등록 건수만 확인했다.

공개 본문은 HTTP 200이며 배포한 로컬 파일과 동일하다. SHA256: `37829e281c5a5444f78cc51907e0866395d92c6ac11a69a9e3fde5a849635c18`.

이번 점검은 구현·운영 사실과 공개 설명의 대조다. 스토어에서 내려받은 최종 앱의 전체 네트워크 동작을 재현하지는 않았다. 문의 메일의 실제 파기 등 수동 업무나 외부 업체의 실제 처리 국가·계약상 역할도 별도 확인이 필요하다. 방침 수정·재배포·서버 설정 변경·백업 삭제·커밋·푸시는 수행하지 않았다.

## 추가 확인이 필요한 사항

- **만 14세 이상 이용 정책**: 정책을 유지하는지, 실제 확인 장치를 복구하는지 운영 결정을 먼저 확정해야 한다. 자동 전송하는 minimumAgeConfirmed를 사용자 동의 기록이라고 표현해서는 안 된다.
- **문의 메일 처리 종료 후 1년 파기**: 앱/서버 코드로 메일함의 수동 파기를 입증할 수 없다. 실제 운영 절차 확인이 필요하다.
- **외부 업체의 실제 처리 국가·보유기간·역할**: Google 광고, Apple 구매/주소 변환, 카카오 검색, Android 플랫폼별 주소 변환 및 Cloudflare Tunnel에 대해 실제 설정·계약·제출 SDK 버전 기준으로 확정해야 한다. 기존 05의 ‘모두 처리수탁자’ 설명도 함께 검토한다.
- **Analytics 새 활동 시 보관기간 재설정**: 관리 API 응답에는 해당 필드가 별도로 없었다. 보관 2개월은 직접 확인했으나 이 항목은 관리자 화면/기본값과 함께 재확인하면 좋다.
- **구매정보 범위**: 앱은 스토어 제공 거래/검증 자료를 처리하지만 카드번호를 날씨 서버가 수집하는 경로는 확인되지 않았다. 구매 안내를 추가할 때 서버가 결제수단을 직접 보관한다고 확대 해석하지 않는다.
- **위치 유래 공용 캐시**: 공용 날씨 DB에는 위치에서 계산한 캐시 키와 지역 판정 결과가 있을 수 있다. `collectedWeatherRepository.ts:47`은 소수점 3자리 좌표 기반 해시 키, `resolvedLocation.ts:14`는 좌표 기반 SHA256 키를 만든다. 설치 삭제는 이 공용 캐시를 대상으로 하지 않으므로 공용 기상자료와 위치 유래 캐시의 보관·삭제 범위를 구분해 확인한다. 이것만으로 개인별 이동 경로를 저장한다고 결론 내릴 수는 없다.
- **로컬 코드와 운영 버전 차이**: 로컬·시험의 30일 미사용 FCM 토큰 정리 코드가 현재 운영 릴리스에는 없다. 이 기준은 공개 방침의 1년 안내와 별개이며 앱 내부 도움말에는 30일 설명이 있으므로 운영 배포와 함께 맞춰야 한다.
