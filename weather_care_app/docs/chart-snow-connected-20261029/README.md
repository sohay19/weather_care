# 신적설 하한 점의 시간 연결선

19시의 0cm와 20시의 2cm 이상 하한 점을 꺾은선으로 연결했다. `2cm 이상`의 수직 범위선·띠·끝막대는 그리지 않는다. 원본 하한·상한 없음·문구를 보존한다.

상한 없는 신적설 하한 점은 연속한 시각의 같은 신적설 계열과 연결하며, 결측·빠진 시간·다른 계열을 연결하지 않는다. 표시 선분과 동일한 도형으로 수치 충돌을 검사한다. 막대 위 기본 수치와 충돌 시 내부 이동, 과거 관측/미래 예보 구분도 유지한다.

`03-snow-ranges.png`가 수정 결과다. 제품 위젯과 한글 글꼴로 검사용 자료를 비표시 렌더링한 예시이며 실기기/운영 자료가 아니다. 앞선 예시는 이전 폴더에 보존했다.

관련 7파일 현재 187개 검사 모두 통과, 전체 정적 분석 이슈 없음. 추가 래스터 검사로 19~20시 중간의 선분 픽셀과 위쪽 수직 범위선 부재를 확인했다.
