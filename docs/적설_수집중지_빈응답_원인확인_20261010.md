### 공식 기록 기준과 가장 유력한 설명

[기상청 기후통계지침(2021.5)](https://data.kma.go.kr/resources/images/publication/%EA%B8%B0%ED%9B%84%ED%86%B5%EA%B3%84%EC%A7%80%EC%B9%A8%282021.5%29.pdf)의 인쇄 68쪽, 부록 A 1.3.18.2는 **3시간 최심신적설**의 기록 기준을 설명한다. 관측장소 절반 이상이 눈으로 덮였지만 깊이를 측정하기 어려우면 0.0cm를 기록하고, 현상이 없거나 절반 미만으로 측정하기 어려우면 공란으로 둔다. 따라서 해당 통계에서 ‘눈 현상이 없는 날에도 항상 0cm 수치가 기록된다’는 전제는 맞지 않는다.

이 기준과 원본 빈 응답을 함께 보면 **적설 현상이 없는 시기의 공란에 대해 일 최심신적설 수치 행이 생성·표출되지 않은 경우**가 가장 유력하다. 이는 원자료의 기록 방식에 관한 추론이며, 특정 날짜의 제공처 처리 원인을 확정한 결과는 아니다.

2026.3 지상기상관측지침의 적설 정의도 관측장소 절반 이상의 피복 기준을 설명하지만, 위 API의 공란 행 생략 조건을 설명하지 않는다. 2021 지침을 2026년 API 내부 구현의 직접 증거로 취급하지 않는다.

### 아직 확정하지 못한 부분

[지상 및 AWS 일통계 공식 명세](https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=239)는 `sd_day_max`의 의미와 요청·응답 필드를 설명하지만, 공란·무현상·미관측 지점에 대한 행 생략 조건과 별도 적설 일자료와의 집계 차이는 공개하지 않는다. 따라서 **10/8·9의 실제 원자료가 무현상 공란이었는지, 별도 지점·집계·제공 정책 때문에 제외됐는지는 기상청 확인이 필요**하다.

위 미확정 사항은 자료 대조 전 조사 단계의 한계다. 최신 대조에서는 공개 공식 관측자료의 24개 유인 관서에서 해당 날짜 수치 공란·눈 관련 현상 기록 부재를 확인했으며, 제공처 내부 관측 로그와 API 행 생략 구현은 여전히 미확정이다. 인증·통신 실패나 숫자를 잃는 파서 결함은 원인으로 확인되지 않았다. 빈 행을 0cm로 바꾸거나 별도 API의 674개 0을 기존 자료의 복구값으로 덮어쓰지 않는다. 과거 최심신적설 복원·신규 일자료 연결은 앞선 사용자 제외 결정대로 진행하지 않는다.

제공처에 확인할 질문은 다음과 같으며 문의는 발송하지 않았다.

> `sfc_aws_day.php obs=sd_day_max stn=0`의 2026-10-08·09 조회는 HTTP 200에 데이터 0행입니다. 같은 날짜 `kma_snow_day.php sd=day snow=2`는 674개 지점의 0cm를 반환합니다. 무적설·공란·미관측에 대한 두 API의 행 표출 조건 및 관측망·일집계 차이를 확인 부탁드립니다. 기존 API가 해당 날짜의 행을 반환하지 않은 실제 사유도 확인 부탁드립니다.

기존 일통계 명세의 `stn=0`은 전체 지점 선택이다. 전 지점의 빈 값을 0cm로 채워 반드시 행을 반환한다는 보장은 명시되지 않았다. 별도 적설 API의 `snow=0/1/2`는 지점 표출 범위를 선택하는 다른 계약이므로 그 설명을 기존 API의 내부 생략 규칙으로 적용하지 않는다.

웹 검색 후에도 판정은 **‘무현상·미관측 등으로 적설 수치 기록이 없는 상태와 부합하지만, 기존 API의 실제 행 생략 조건 및 해당 날짜의 사유는 미확정’**이다. ‘0cm를 무조건 생략한다’거나 ‘눈이 없었던 것으로 확정됐다’고 변경하지 않는다. 제공처 문의 내용은 작성자·관리자만 열람할 수 있다는 [개방포털 안내](https://data.kma.go.kr/community/detailError.do)도 확인했다. 타인의 비공개 문의를 열람하거나 문의를 발송하지 않았다. 이번 작업은 웹 조사와 기록 갱신이며 앱·서버 코드·운영 설정·배포·커밋은 변경하지 않았다.

## 문의 없이 가설을 검증하는 방법

문의 외에도 **동일 지점·동일 날짜의 관측 원자료와 기존 API 응답을 교차 대조**할 수 있다. 아래는 검증 방법이며, 전체 지점 대조를 이미 수행했다는 뜻은 아니다.

1. [종관기상관측(ASOS) 자료 조회](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36)에서 10/8·9의 일 최심신적설과 눈 관련 일기현상 기록을 확인한다. 목측 수행 여부를 함께 확인해 무현상 공란과 미관측·실제 누락을 구분한다. 시간·분자료 QC 플래그는 공식 설명에 열거된 항목만 대상으로 하므로 적설 전용 오류 판정으로 사용하지 않는다.
2. 기존 겨울 2/1~7 응답의 양수 29행·명시적 0 한 행을 대조군으로 삼는다. 공란 날짜뿐 아니라 명시적 0과 양수 날짜를 같은 지점 기준으로 비교해야 0 생략·계절 문제·특정 관측망 문제를 구분할 수 있다.
3. 필요 시 승인된 기존 엔드포인트에서 시작일·종료일을 명시하고 전체 지점/개별 지점 조회를 대조한다. 원자료에 유효 수치가 있는데도 원문 행이 없으면 무현상 공란 가설로 설명되지 않으며 집계·제공 경로 차이 또는 오류를 추가 조사한다. 수치 없는 날에만 행이 없고 값 있는 날은 반환되는 반복 대조는 가설을 지지하지만 내부 구현 규칙을 확정하지는 않는다.

[날씨누리 과거관측 일별자료](https://www.weather.go.kr/w/weather/land/past-obs/obs-by-day.do)는 개방포털 자료를 API로 제공하는 보조 조회 경로다. ASOS와 완전히 독립된 관측값으로 세지 않는다. 이번에 공개 서울 2026년 10월 달력의 10/8·9 기온·강수 표시를 읽을 수 있는 것은 확인했지만, 그 기온만으로 무적설을 확정하거나 전국 지점의 신적설 원자료 대조가 끝났다고 취급하지 않는다. 별도 적설 API의 전 지점 0 응답만으로도 가설을 확정하지 않는다.

자료 대조로 ‘관측 정상·무현상·수치 공란과 행 미반환의 일치’를 실증할 수 있다. 공식 행 생략 정책 자체를 확정하려면 공개된 제공 규칙·처리 구현 또는 제공처 설명이 추가로 필요하다. 이번 작업에서는 방법과 공개 조회 경로만 확인했고 신규 인증 API 호출·권한 신청·문의 발송은 하지 않았다.
