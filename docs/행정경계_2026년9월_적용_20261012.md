# 2026년 9월 구역의 도형 적용 기록

## 원본과 변환

- 원본: `docs/경계/구역의도형_전체분_*.zip` 16개. 사용자가 승인받아 내려받은 2026년 9월 월전체분이다. ZIP 안의 `TL_SCCO_GEMD` 행정동 SHP·SHX·DBF만 사용한다. 정확한 일자 기준일은 파일에 없으므로 **2026년 9월 기준월**로만 표시한다.
- 좌표는 국내 EPSG:5179 평면좌표로 확인하고 WGS84로 변환한다. DBF는 CP949로 읽는다. 시흥시 은행동의 알려진 좌표와 전국 범위로 좌표계 해석을 검증한다.
- 3,564개 도형 전체와 원본 링·구멍·섬을 보존한다. 격자 교차 계산에서만 자기 교차 22개를 면적 변화 1㎡ 이하로 보정했다. 서버에 저장하는 GPS 판정용 링은 원본 좌표 그대로다.
- 기상청 카탈로그와 코드가 같은 행정동 3,560개를 동 단위로 연결했다. 카탈로그에 없는 `2771026800 구지읍`, `3611055800 집현동`, `2815555000 운서2동`, `2815556000 용유동` 4개는 코드 앞 5자리로 검증된 상위 구역만 연결한다. 임의의 이웃 동을 선택하지 않는다.
- 같은 코드의 이름이 다른 2건은 별도 기록했다. `4812556500`은 원본 `반월중앙동`/현재 카탈로그 `중앙동`, `5013025000`은 원본 `대정읍`/카탈로그 `대정읍/마라도포함`이다. 코드는 같아 동 단위 연결을 유지하지만 화면 이름은 카탈로그 이름이다.
- 시·도 ZIP SHA-256과 카탈로그 내용 해시로 경계 버전을 만든다. 자료·변환 규칙이 바뀌면 다른 버전으로 게시되고 기존 GPS 위치 캐시는 재판정된다.

## 검증

| 항목 | 결과 |
|---|---:|
| 원본 ZIP CRC | 16/16 정상 |
| 도형 내부 GPS 표본 | 3,564/3,564 연결 |
| 기존 모호한 425격자의 육지 표본 | 4,367/4,367 연결 |
| 기존 모호한 425격자의 중심 | 동 409, 경계 밖 16 |
| 전국 육지 교차 예보 격자 | 4,705개 |
| 좌표 없는 전국 격자의 보수적 상위 참조 | 2,711개 |
| 여행지·은행동 메인/오늘/주간 | 6/6 HTTP 200 |
| 검증 중 외부 제공처 호출 | 0회 |

구역 도형의 이웃 링 사이에는 수 mm 수준의 접합 오차가 있다. 전체 격자 상위 참조 계산에만 최대 1cm의 접합 허용치를 두고, 실제 해안·빈 영역이나 다른 상위 행정구역을 넘는 격자는 제외한다. 이전 2025년 2분기 경계의 상위 참조 2,848개·육지 격자 4,728개와 숫자가 달라졌다. 좌표 없는 모호한 격자 425개 중 상위 참조가 확정된 것은 243개다. 나머지는 정확한 GPS나 사용자가 확정한 지역 코드가 필요하다.

검증 결과 원본은 [JSON](행정경계_2026년9월_검증_20261012.json)에 보존한다. 서버 TypeScript 검사와 경계 단위 테스트 10개가 통과했다. GPS 판정은 실제 도형·합성 기상 자료로 검사했으며 운영 API의 모든 시각·모든 좌표를 전수 확인한 결과는 아니다.
