# Week 날짜 카드 전환 애니메이션

날짜 선택·이전/다음 화살표·카드 스와이프에서 280ms 좌우 슬라이드와 페이드 전환을 적용했다. 다음 날짜는 오른쪽에서, 이전 날짜는 왼쪽에서 들어오며 카드 높이도 부드럽게 맞춘다. 애니메이션 줄이기 설정에서는 즉시 전환한다.

나가는 카드는 터치와 접근성 탐색에서 제외한다. 빠르게 날짜를 다시 선택해도 마지막 카드 한 장으로 정리한다. 날짜가 같은 자료 갱신에서는 카드 전환을 재생하지 않는다.

- [실제 연결 기기 전환 영상](week-card-animation.mp4): SM-S948U, 1080×2340. 스와이프 양방향과 날짜 화살표를 실제 조작해 촬영한 영상이며 합성 예시가 아니다.
- [애니메이션 적용 후 실기기 회귀 검사](실기기_회귀_검증.json): 고정 세로축, 필터 양끝, 카드 하단 여백의 이전·다음 날짜 전환 5건 통과.

관련 Flutter 검사 142개와 전체 정적 분석이 통과했다. 최신 제품 화면을 사용하는 기존 확인용 앱을 데이터 보존 업데이트해 확인했다. 기기 프로세스의 Flutter 오류·치명 예외·ANR 로그는 0건이다. 일반 main.dart 제품 Debug APK 빌드도 완료했다. 실제 기기는 오늘 Week의 카드 상단과 날짜 화살표가 보이도록 두었다.

제품 변경은 `lib/features/home/tabs/week_tab.dart`, 추가 검사는 `test/week_tab_test.dart`다. 기존 그래프·필터 가로 스크롤 영역을 유지하며 기기 전체의 애니메이션 설정은 변경하지 않았다. 서버/스토어 배포와 커밋·푸시는 수행하지 않았다.
