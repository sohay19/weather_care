# 대기질 전국 조회

적용일: 2026-09-10

## 지역과 측정소 선택

- 기존에는 정밀 좌표가 없는 조회가 `regionCatalog.ts`의 서울·수원 고정 측정소에 의존했다. 이 제한을 제거했다.
- 정밀 GPS 좌표가 제공되면 그 좌표를 사용한다. 좌표가 없으면 요청한 기상청 5km 예보 격자를 역변환한 대표 지점을 사용한다. 대표 지점은 사용자의 실제 GPS 위치가 아니다.
- 기상청 날씨누리 `convertDfsGrid`와 동일한 Lambert 투영을 사용한다. 서버의 새 `kmaGridCoordinates.ts`는 기존 Flutter 순변환과 같은 상수를 쓴다.
- 에어코리아의 공식 측정소 좌표 목록 전체를 받은 뒤 앱이 직선거리 순으로 정렬한다. 공식 근접측정소 API의 판정을 그대로 가져오는 방식은 아니다.
- 가까운 후보 최대 5곳에서 사용 가능한 관측을 확인하고 실제 선택된 한 측정소의 PM10·PM2.5·오존을 사용한다. 서로 다른 측정소의 수치를 평균하거나 결측 항목을 다른 측정소 값으로 메우지 않는다.
- 측정소는 행정구역 경계를 넘을 수 있다. 전국 조회 지원은 모든 동네·도로·실내에 측정소가 있다는 뜻이나 사용자 지점 실측의 정확도를 보장하는 뜻이 아니다. 도서·산간에서 가까운 측정소도 멀 수 있다.

## API·캐시 계약

- Today 조회와 알림 스케줄러가 공통 `loadEnvironmentalData`를 사용하므로 같은 지역 선택 로직을 따른다. 알림의 수치 기준·설정·발송 시각·중복 방지 정책은 변경하지 않았다.
- `AIR_STATIONS_V1`: 검증된 측정소명과 공개 좌표 목록을 기존 D1 `weather_cache`에 24시간 공유 캐시한다. 실패한 응답이나 불완전한 목록은 저장하지 않는다. 목록이 만료되고 갱신도 실패하면 대기질은 확인 불가로 처리한다.
- 목록의 `totalCount`, `pageNo`, `numOfRows`를 확인하며 후속 페이지를 읽는다. 최대 10페이지, 응답당 2MiB를 넘는 비정상 자료는 거부한다. 정상 좌표가 없는 행은 후보에서 제외하고 중복 측정소명은 한 번만 조회한다.
- `AIR_STATION_V1_{측정소명}`: 관측은 측정소별로 30분 캐시한다. 같은 격자 안에서 다른 GPS 지점으로 이동해도 다른 측정소 캐시와 섞이지 않는다. 기존 `AIR_{nx}_{ny}` 캐시는 읽지 않으며 삭제하지 않았다.
- 관측 조회 실패 시 기존의 최대 3시간 캐시 fallback을 유지하되, 관측 시각 자체도 기존 Provider 허용 범위(과거 4시간/미래 1시간) 안인지 확인한다. 오래된 관측을 새로 캐시했다는 이유만으로 다시 사용하지 않는다. STALE 상태·관측 시각을 보존한다.
- 누락·음수·유효하지 않은 시각·요청과 다른 측정소 자료를 정상값으로 만들지 않는다. 자료 실패는 `UNAVAILABLE`이며 정상 격자를 `UNSUPPORTED_REGION`으로 처리하지 않는다. 대기질 실패가 기상예보 전체를 실패시키지는 않는다.
- 전국 대기질 조회 한 번의 외부 요청 시간은 공통 6초 신호로 제한한다. Today의 기존 선택 Provider 응답 대기 예산과 완료 후 캐시 작업은 유지한다.
- 새 바인딩·비밀값·DB 스키마 변경 없음. 공개 측정소 목록과 관측만 캐시에 추가하며 사용자 정밀 좌표를 새 캐시 키나 payload에 저장하지 않는다.

## 앱 표시

- Main의 기존 대기질 지표에 실제 관측 수치가 연결된다.
- Detail → 미세먼지/초미세먼지 지표를 누르면 실제 측정소명, 한국시간 기준 월·일·시·분과 사용자 자리에서 직접 측정한 농도가 아니라는 설명을 표시한다.
- 측정소명·관측 시각이 없는 구버전 응답에서는 해당 정보 없음으로 안내한다. 지역명이나 예보 시각을 관측 정보로 대신 쓰지 않는다.
- 설정의 데이터 출처 안내에도 전국 조회와 GPS/격자 기준의 차이를 추가했다. 정밀 좌표가 없어도 대기질을 조회할 수 있지만, 현재 비·정밀 도로 안내의 좌표 조건은 그대로다.

## 검증

- 기상청 공식 JS를 독립 실행한 8개 지점(기준점·서울·수원·부산·제주·울릉·독도·서해 도서)과 역변환값을 비교했다. 격자 유효 범위와 잘못된 입력도 검증했다.
- 미등록 전국 격자, GPS 우선, 격자/측정소 캐시 분리, 오래된 관측 캐시, 전체 페이지 수집·불완전 페이지 거부, 후보 제한·결측 fallback·오류 자료·응답 크기를 테스트했다.
- 전체 서버 29파일/212 tests와 `tsc --noEmit`, 앱 294 tests·`flutter analyze`·Android debug APK 빌드 통과. 상세 표시의 UTC/KST·결측, 기존 360px/2배 글씨 테스트를 포함한다.
- 운영 배포: `be6a875e-55c3-4e21-837b-641ecd195f50`. `/health` 정상. 2026-09-10 18:37 KST에 672개 측정소가 검증된 목록 캐시에 저장됐다. 해당 목록의 중복 측정소명은 없었다.
- 같은 시각 좌표 없는 실조회 9곳 모두 HTTP 200 / 대기질 AVAILABLE: 서울→종로, 부산→좌동, 대전→월평동, 광주→치평동, 대구→남산1동, 춘천→신사우동, 제주→연동, 울릉→울릉읍, 백령→백령도. 이는 표본 운영 검증이며 전국 모든 격자의 매시각 자료 제공을 보장하지 않는다.
- 에뮬레이터 데이터 유지 설치 후 Main의 PM2.5 수치 및 Detail의 `인계동 측정소 · 9월 10일 18시 00분 관측`을 확인했다. 지역·권한·알림 설정 변경과 실제 테스트 푸시 발송 없음. iOS/실기기는 미검증.

## 남은 운영 확인

- 외부 API 점검·측정소 결측·호출 한도 초과 시 자료가 없을 수 있다. 이용자 확대 전 실제 계정의 호출 한도와 운영계정 조건은 별도로 확인한다. 한도를 자동 변경하거나 유료 계약을 신청하지 않았다.
- 정식 개인정보처리방침은 기능 출처 안내와 별개다. 운영 주체·연락 경로·보유/삭제 조건·외부 처리·공개 URL 확인 후 연결해야 한다.
