# 기상청 APIHub 문의 초안 — 아직 제출하지 않음

제목: 단기예보 연장 구간의 VEC 전국 격자 응답만 HTTP 200/0B — 지점별 API는 정상

안녕하세요. 단기예보 전국 격자 API의 풍향 제공 차이에 대해 내부 확인을 요청드립니다.

서비스: `/api/typ01/cgi-bin/url/nph-dfs_shrt_grd`

- 발표 `tmfc=2026100905`, 변수 `vars=VEC`
- 유효시각 `tmef=2026101203/06/09/12/15/18/21`, `2026101300` 총 8개
- 여러 차례 HTTP 200, 응답 본문 0바이트를 받았습니다.
- 같은 발표의 `tmef=2026101200`, `vars=VEC`는 HTTP 200, 341,297바이트이며 149×253개 격자 값이 정상입니다.
- `tmfc=2026100908` 및 `2026100817`, `tmef=2026101203`, `vars=VEC`도 HTTP 200/0바이트입니다.
- `tmfc=2026100905`, `tmef=2026101203`의 TMP/WSD/UUU/VVV는 정상 자료를 반환했습니다. WSD는 위 8시각 모두 수집되어 있습니다.

교차 확인: 공공데이터포털 `/1360000/VilageFcstInfoService_2.0/getVilageFcst`에 `base_date=20261009`, `base_time=0500`, `nx=71`, `ny=130`을 요청하면 같은 8시각 VEC가 순서대로 70,59,73,75,169,180,27,90도로 제공됩니다. 동일 격자를 응답하며, 정상 결과코드 00, 전체 907행을 반환합니다. 따라서 연장일 풍향 예보 자체는 제공되고 있습니다.

APIHub 공개 규격과 2024-11-28 예보기간 확대 문서는 연장 구간과 VEC를 안내하고 있습니다. 다음 사항을 확인 부탁드립니다.

1. VEC 격자 파일 생성 또는 게시 과정에서 연장일 자료가 누락되는지
2. `nph-dfs_shrt_grd`의 VEC 조회가 예보기간 확대 이전 종료 시각을 적용하는지
3. 지점별 예보와 전국 격자 VEC의 제공 범위를 다르게 운영하는 정책이 있는지, 있다면 공식 안내 위치
4. 해당 자료 부재를 HTTP 200/빈 본문으로 응답하는 이유와 수정 계획 또는 권장 조회 방법
5. 일부 요청은 DNS/TCP/TLS 연결이 약 0.03초 이내 완료됐지만 첫 응답 바이트 없이 30초에 종료되고, 같은 요청 재조회는 2초 이내 정상입니다. 관련 API 응답 처리 지연 또는 장애 기록이 있는지

관측: 2026-10-09 09:15~09:37 KST의 격자 요청, 09:49 KST의 공공데이터포털 지점별 대조. 본문 0B는 별도 curl에서도 재현됐으며 파싱 전 수신 단계에서 확인했습니다. 인증키는 문의 본문에 포함하지 않았습니다.

별도 참고: APIHub `/api/typ02/openApi/VilageFcstInfoService_2.0/getVilageFcst` 비교는 403으로 중단했으므로 해당 경로의 자료 상태는 확인하지 못했습니다. 이 권한 문제를 위 typ01의 HTTP 200/0B 원인과 혼동하지 않습니다.
