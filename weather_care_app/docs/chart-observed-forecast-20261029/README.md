# 확률 수치의 자기 막대 내부 배치와 적설 관측·예보 구분

이 폴더는 이전 결과를 보존한다. 막대 위 수치를 기본으로 복원하고 `2cm 이상` 신적설을 점으로 바꾼 최신 예시는 [최신 그래프 예시](../chart-label-final-20261029/README.md)에 있다.

## 적용 내용

- 강수·강설확률 수치는 자기 막대 안에 빈 공간이 있으면 내부에 우선 배치한다. 선·점·범위·다른 수치 및 다른 막대와의 충돌은 계속 검사한다. 선 수치를 먼저 점 가까이에 놓고 그 뒤 확률 수치를 배치한다.
- 막대가 너무 낮거나 내부에 공간이 없으면 가까운 바깥 공간을 사용한다. 0%처럼 높이가 없는 막대의 수치도 생략하지 않는다. 단독 습도 그래프의 기존 막대 위 수치는 유지한다.
- 막대 안의 모든 수치는 계열 색을 유지하고 글자 둘레 대비를 보강한다.
- 이 화면의 신적설은 앞으로 새로 내릴 눈의 예보이며 현재 적설량은 실제 관측이다. 지난 시각에는 신적설·확률 예보를 숨기고 관측 적설량만 표시한다. 관측이 없는 시각은 예보로 채우지 않는다.
- 신적설·확률은 현재 시각 이후 시작하는 1시간 구간에 표시한다. 정시와 시작이 정확히 같은 구간은 예보를 유지하며, 시작 시각이 지나면 관측만 표시한다. 이미 진행 중인 구간의 일부를 미래 예보로 새로 나누거나 환산하지 않는다.
- 미래 시각의 관측 자료는 제외하며 다른 날짜와 관측소를 섞지 않는다. Main·Week 모두 같은 기준이다.
