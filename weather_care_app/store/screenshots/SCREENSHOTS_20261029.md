# Android 스토어 스크린샷 여백 축소 · 2026-10-29

10월 28일 연결 Android에서 촬영한 실제 앱·위젯 원본을 사용해 등록 이미지의 여백을 줄였다. 2번 지역별 알림과 기존 8장 순서는 유지한다.

- 휴대전화 등록 규격: `android/`의 1080×2160 RGB PNG 8장
- 태블릿 등록 규격: `android-tablet/`의 1440×2880 RGB PNG 8장
- 압축파일: `../weather-care-android-screenshots-20261029.zip`
- 전체 미리보기: `preview-android.png`, `preview-android-tablet.png`
- 이미지 해시: `screenshots-20261029-manifest.json`

## 배치 변경

- 제목과 본문의 전체 구성 바깥 여백을 상하좌우 각각 72px로 통일했다. 직전 좌우 48px의 1.5배이며, 태블릿 규격에서는 같은 비율의 96px다. 그림자도 바깥 여백 안으로 제한했다.
- 제목은 60px의 큰 두 줄 글씨를 유지하고 줄간격을 -4px에서 16px로 늘렸다. 작은 분류명과 부연 설명은 생략했다.
- 제목 마지막 글자 아래와 이미지 사이에도 바깥 여백과 같은 72px 간격을 넣었다. 태블릿에서는 96px다. 그림자도 이 간격을 침범하지 않는다.
- 앱 화면과 알림 예시는 제목 높이를 반영한 남은 높이에 맞춰 비율을 유지해 배치하며, 아래쪽 여백 72px를 남긴다.
- 앱 화면 전체와 탭 메뉴를 유지하도록 세로 2:1 규격을 적용했다. 원본의 비율·글자·수치를 유지하며 앱 화면을 추가로 자르거나 늘리지 않았다.
- 소형·중형·대형 위젯을 각각 400·936·900px 너비로 배치하고 위젯 사이의 간격을 조정해 아래 여백을 맞췄다. 작은 크기 라벨은 생략해 제목과 이미지 사이를 비웠다. 다크모드의 대형 위젯도 실제 촬영본을 사용한다.
- 알림 예시 카드를 가로에 가깝게 채우고 글씨를 키웠다. 긴 본문은 카드 안에서 줄바꿈한다. 5번은 홍보용 예시이며 실제 OS 알림 수신 화면이 아니다.

세로 2:1은 Google Play의 긴 변이 짧은 변의 두 배 이하인 이미지 조건에 맞춘 규격이다. [공식 이미지 등록 안내](https://support.google.com/googleplay/android-developer/answer/9866151?hl=ko)

## 원본과 보존 범위

실제 앱 원본은 `source-android-20261028/`, 실제 Android AppWidgetHost 원본은 `native-android-20261028/`다. 촬영 기기·데이터·원본 해시는 [10월 28일 촬영 안내](SCREENSHOTS_20261028.md)를 따른다. 새 촬영이나 기기 설정 변경은 하지 않았다.

태블릿 규격도 같은 휴대전화 촬영본으로 구성한 소개 이미지다. 실제 태블릿 촬영본은 아니다. iOS·iPad·Google Play 그래픽과 기존 압축파일은 보존했다. 10월 28일 압축파일에는 이전 여백의 결과가 남아 있다.

앱 루트에서 다시 생성한다.

```powershell
python -X utf8 store/generate_android_store.py --screenshots-only
```
