# iOS 스토어 스크린샷 · 2026-10-23

최신 Android 실제 촬영본과 같은 기준으로 Main·Week UI를 반영했다. 앱 화면은 실제 설치·실행한 제품 앱을 촬영하며, 상단 시스템 상태바와 하단 홈 표시 영역만 제외한다. 앱 탭 메뉴와 화면의 원래 배치를 유지하고 부분 카드를 분리하거나 조위 그래프를 덧붙이지 않는다. 4번에만 실제 다크 대형 위젯을 함께 배치한다.

후속 요청에 따라 iPhone·iPad 각 8장의 제목·설명·앱 화면·위젯·알림 예시를 한 묶음으로 세로 중앙에 정렬했다. 기존 크기와 내부 간격을 유지하며 위아래 여백이 균형을 이루도록 전체 묶음의 위치를 조정한다.

## 촬영 기준

앱은 현재 작업 트리를 Flutter 3.47.4로 빌드하고 전용 iPhone 15 Pro Max/iOS 17.5 시뮬레이터에 설치했다. 예시 자료를 주입하는 Flutter 테스트 화면을 사용하지 않는다. Main·타임라인·Week·위젯은 부산광역시 남구 감만1동의 운영 서버 실자료이며, 촬영 시각 차이로 수치와 기준시간이 일부 다를 수 있다. 심화 날씨는 사용자 요청에 따라 테스트 서버의 실제 관측 자료를 표시한 앱을 촬영한다. 인증 키는 이미지·명세·ZIP·문서에 포함하지 않는다.

Main의 지금 날씨·오늘의 기온·통합된 어제 비교와 Week 날짜별 기온·생활 정보가 잘 보이는 위치로 스크롤한다. 1.1배 글자 제한, 15px Main 제목과 간격, 최저·최고 수치의 파랑·빨강 색상을 반영했다. 시간별 그래프와 한글·수치는 실제 앱 화면 그대로다.

앱 전체 원본은 1290×2796이며 실제 상태바 59pt(177px)와 홈 표시 영역 34pt(102px)만 제외한다. 1290×2517의 나머지 픽셀을 그대로 저장하고, 홍보 이미지에서 비율 유지 축소·배치·그림자를 적용한다. iPad 등록용 앱 이미지는 최신 Android 태블릿 제작 방식과 같이 동일한 iPhone 원본을 비율 유지해 배치한다. 실제 iPad 앱 화면 촬영으로 설명하지 않는다.

홈 위젯은 같은 제품 앱이 저장한 실자료를 사용한다. iPhone 15 Pro Max/iOS 17.5와 iPad Pro 13형 M4/iOS 18.6의 SpringBoard에서 소형·중형·대형을 라이트·다크로 각각 직접 촬영했다. 위젯 바탕색 경계 밖 홈 배경만 투명하게 제거하고 불투명한 내부 픽셀 보존을 검사한다. 예시 자료를 쓰는 별도 위젯 호스트를 실행하지 않는다.

5번은 기존 알림 예시 5개를 사용하며 최신 Android와 같이 하단 예시 안내 문구를 삭제했다. 실제 푸시 발송·알림 센터 촬영으로 표현하지 않는다. 8번은 촬영용 기기의 실제 알림 설정 화면이다.

전체 원본·접근성 트리·명령·빌드/XCTest 결과와 변경 전 백업은 ignored `build/ios-live-store-20261023/`에 보관한다. 배포용 크롭 폴더에는 원본 해시·크롭 좌표·기기 정보도 기록한다. Android·그래픽과 과거 촬영 원본은 유지하며 통합 ZIP에 최신 iOS 결과와 재생성 도구를 반영한다.

## 다시 만들기

실제 촬영은 `../native_ios_app_capture/README.md`를 따른다. `capture_ios_test.dart`는 과거 예시 렌더링용이므로 이번 원본 제작에 사용하지 않는다. 최종 등록 이미지만 다시 내보내려면 앱 루트에서 실행한다.

```sh
python3 store/generate_ios_store.py
```

기존 사용자 기기·권한·위치·기존 실행 시뮬레이터는 변경하지 않았다. 서버 배포·자료 단발 수집·실제 푸시·스토어 제출은 수행하지 않았다.
