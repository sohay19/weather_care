# Week 스와이프 영역 반영 확인

2026-10-29, 연결 SM-S948U(1080×2340)에서 최신 제품 화면을 사용하는 기존 확인용 앱 `com.codesoha.weathercare.storecapture`를 데이터 보존 업데이트해 확인했다.

- 필터 가로 스크롤 영역은 카드 테두리 안쪽 양끝까지 확장했다. 칩의 시작 위치는 유지했다.
- 그래프 영역은 왼쪽 고정 세로축부터 오른쪽 끝까지 같은 여백으로 넓혔다. 강수·강설의 오른쪽 세로축과 하단 시간 표시도 같은 그래프를 스크롤한다.
- 카드 하단 여백에서는 이전·다음 날짜로 이동한다. 필터·그래프의 양끝에 도달하거나 항목이 한 건이어도 가로 동작이 날짜 전환으로 넘어가지 않는다.
- Main의 기존 스크롤 동작은 유지하고 Week 일반/자료 없음 카드에 함께 적용했다.

관련 Flutter 테스트 135개, 변경 대상 3파일 정적 분석, 확인용 APK와 일반 `main.dart` 제품 Debug APK 빌드가 통과했다. 실기기에서 제스처 9건을 검사했으며 현재 앱 프로세스의 Flutter 오류·치명 예외·ANR 로그는 0건이다.

카드 최하단의 실제 좌표는 카드 `[45,105]–[1035,1907]`, 세로축·시간 표시를 포함한 기온 그래프 `[70,771]–[1010,1856]`이다. 그래프의 양옆 여백은 각 25px이고 그래프 아래 카드 안 여백은 날짜 전환 영역이다. 화면 폭·배율에 따른 실제 좌표이며 앱에는 논리 픽셀로 반영했다.

날짜 선택과 그래프 스크롤 위치를 읽기 전용 Dart VM Service로 확인했다. 세로축 가로 스와이프에서 날짜 인덱스는 1로 유지되면서 그래프 위치가 실제 변경됐고, 카드 하단 여백에서는 날짜 인덱스가 1→2→1로 이동했다. VM 임시 포워드는 검사 후 제거했다. 기기는 오늘의 Week 카드 최하단 기온 화면으로 두었다.

제품 코드 변경은 `week_tab.dart`, `hourly_forecast_section.dart`이며 회귀 검사는 `week_tab_test.dart`에 추가했다. 별도 작업의 그래프 수치 배치 수정은 변경하지 않았다. 서버/스토어 배포와 커밋·푸시는 수행하지 않았다.
