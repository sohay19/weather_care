# 날씨챙겨 공공데이터포털 운영계정 신청 입력 초안

작성 기준: 2026-10-01  
상태: **입력 초안**. 공공데이터포털에 제출하거나 승인받은 상태가 아닙니다.

첨부된 PDF는 웹 신청 화면을 인쇄한 것으로, 입력 가능한 PDF 양식이 아닙니다. 아래 코드 블록의 내용만 복사해 각 입력칸에 붙여넣으세요.

## 1. 신청할 서비스와 우선순위

| 우선순위 | 공공데이터포털 서비스 | 현재 사용과 판단 |
| --- | --- | --- |
| **필수** | [기상청_단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do) | `getVilageFcst` 전국 1,633격자 × 하루 8회 발표 = 기본 13,064회/일. 개발계정 기본 10,000회/일보다 많습니다. `getUltraSrtNcst`도 같은 서비스에 속합니다. |
| **출시 전 전환 권장** | [한국환경공단_에어코리아_대기오염정보](https://www.data.go.kr/data/15073861/openapi.do) | 측정소별 실시간 대기질, 대기질 예보통보, 초미세먼지 주간예보를 사용합니다. 개발계정 기본 500회/일이어서 지역·이용자 증가와 재시도 여유가 작습니다. 현재 초과가 확인된 것은 아닙니다. |
| 승인 상태 확인 | 한국환경공단_에어코리아_측정소정보 | 측정소 목록을 하루 동안 캐시해 사용합니다. 호출량은 낮지만 대기오염정보와는 별도 서비스이므로 활용승인을 확인하세요. |
| 승인 상태 확인 | 기상청_생활기상지수 조회서비스(3.0) | 자외선지수 `getUVIdxV5`를 사용합니다. 현재 한도 초과 기록은 없습니다. |
| 필요 시 | [기상청_중기예보 조회서비스](https://www.data.go.kr/data/15059468/openapi.do) | `getMidTa`, `getMidLandFcst` 코드가 있지만 현재 운영은 APIHub 키가 있으면 APIHub 경로를 우선 사용합니다. 공공데이터포털 경로를 실제 운영할 때 승인 상태를 확인하세요. |

기상청 **APIHub**와 **ITS 도로통제**는 이 공공데이터포털 신청서의 대상이 아닙니다. 첨부 화면에 보이는 `일일 트래픽 100000`은 신청 화면에 표시된 수치이며 **현재 승인된 한도는 아닙니다**. 승인 후 서비스별 실제 한도를 확인해야 합니다.

## 2. 첨부 화면의 단기예보 신청 항목

화면 데이터명: `기상청_동네예보 조회서비스(2.0)_20210628`  
현재 포털 서비스명: `기상청_단기예보 조회서비스`

### 상세기능 선택

- **선택:** `초단기실황조회` (`getUltraSrtNcst`), `단기예보조회` (`getVilageFcst`)
- **선택 해제:** `초단기예보조회`, `예보버전조회` — 현재 서버 코드에서 호출하지 않습니다.

### 활용사례명 * — 50자 이내

```text
날씨챙겨 - 위치 기반 생활 날씨 안내
```

### 국내외 구분 / 개발유형

```text
국내
모바일앱
```

### 분류체계 *

`환경·대기` 또는 `기상`에 가장 가까운 실제 포털 선택지를 고르세요. 첨부 PDF에는 드롭다운 목록이 나오지 않아 정확한 항목명은 확인할 수 없습니다.

### 서비스 URL * — 50자 이내

현재 공개된 **입력 후보**:

```text
https://weather-care.pages.dev/
```

이 주소는 현재 **개인정보처리방침**만 보여주며 날씨 기능을 직접 확인할 수 없습니다. 포털이 요구하는 “활용된 서비스를 확인할 수 있는 URL”로 인정되는지 확인하고, 공개 시연 페이지나 스토어 URL이 준비되면 교체하세요. `https://weather-api.codesoha.com/weather-map`은 현재 HTTP 404여서 입력하지 마세요.

### 개발자 유형 * / 개발자 소재지 * / 서비스 개시일 *

- 개발자 유형: **개인사업자 코드소하(CODESOHA)**. 포털의 실제 선택지 문구에 맞춰 고르세요.
- 개발자 소재지: **신청자가 직접 입력**하기로 했습니다.
- 서비스 개시일: 앱은 **출시 전**입니다. 실제 출시일처럼 과거 날짜를 적지 말고, 포털이 예정일을 받는지 확인한 뒤 **출시 예정일을 직접 입력**하세요.

### 서비스 설명 * — 4,000 bytes 이내

```text
날씨챙겨는 개인사업자 코드소하가 출시 준비 중인 모바일 날씨 앱입니다. 이용자가 GPS 또는 수동으로 선택한 지역을 기상청 예보 격자로 변환하고, 중앙 서버가 기상청 단기예보와 초단기실황을 수집·저장해 기온, 체감온도, 강수, 시간별 날씨와 생활 준비물 안내에 활용합니다. 앱과 홈 화면 위젯은 자체 서버의 결과를 조회하며 공공데이터포털 인증키를 앱에 저장하거나 외부 API를 직접 호출하지 않습니다. 전국 1,633개 지원 격자를 예보 발표 하루 8회에 맞춰 갱신하므로 정규 단기예보 조회만 최소 13,064건/일입니다. 신규 GPS 지역 조회, 일시적인 실패 재시도와 배포 시 보충 수집을 고려해 운영계정의 충분한 일일 트래픽이 필요합니다.
```

### 기능 및 서비스 화면 * — 4,000 bytes 이내

```text
Main 화면은 선택 지역의 현재 관측과 다음 시간 예보를 기온·체감온도·강수 등으로 보여주고, 날씨에 맞는 준비물과 생활 안내를 제공합니다. Today 화면에서는 시간별 날씨와 강수 흐름을, Week 화면에서는 앞으로의 일별 날씨를 확인할 수 있습니다. GPS 이동 또는 수동 지역 변경 시 서버가 해당 격자 자료를 조회해 앱과 위젯에 제공합니다. 신청한 단기예보조회는 시간별 예보에, 초단기실황조회는 관측 보조 및 어제 비교에 사용합니다. 첨부할 실제 앱 화면은 Main, Today, Week 캡처를 권장합니다.
```

## 3. 다른 서비스 신청 시 선택할 상세기능과 용도

서비스별 운영계정 신청은 **별도**로 진행합니다. 공통 활용사례명과 앱 설명을 재사용하되, 실제 사용하는 상세기능만 선택하고 아래 용도 문구를 해당 신청에 추가하세요.

### 에어코리아 대기오염정보 — 출시 전 전환 권장

선택: `측정소별 실시간 측정정보 조회`, `대기질 예보통보 조회`, `초미세먼지 주간예보 조회`

```text
날씨챙겨 앱에서 선택 지역 인근 측정소의 미세먼지(PM10), 초미세먼지(PM2.5), 오존 관측값과 대기질 예보를 표시합니다. 중앙 서버가 측정소별 관측값을 1시간 동안 캐시하고 발표된 예보를 재사용해 중복 호출을 줄입니다.
```

### 에어코리아 측정소정보 — 승인 상태 확인

선택: `측정소 목록 조회`

```text
날씨챙겨 서버가 전국 대기질 측정소 목록을 하루 동안 캐시하고, 이용자가 선택한 지역과 가까운 측정소를 찾아 대기질 관측값의 위치를 결정합니다.
```

### 기상청 생활기상지수 — 승인 상태 확인

선택: `자외선지수 조회` (`getUVIdxV5`)

```text
날씨챙겨 앱의 Today와 Week 화면에서 선택 지역의 자외선지수를 제공하고, 야외활동 준비물과 생활 안내에 활용합니다. 서버는 활성 지역을 중심으로 지수를 수집·캐시합니다.
```

### 기상청 중기예보 — 공공데이터포털 경로 운영 시

선택: `중기기온조회` (`getMidTa`), `중기육상예보조회` (`getMidLandFcst`)

```text
날씨챙겨 앱의 Week 화면에서 4~10일 뒤의 기온과 날씨를 제공합니다. 현재 운영 서버는 KMA_APIHUB_KEY가 설정되어 기상청 APIHub 경로로 수집합니다. 공공데이터포털 중기예보 신청은 현재 운영에 필요하지 않습니다. 해당 경로로 전환할 때 활용승인을 확인하겠습니다.
```
