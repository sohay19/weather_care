# iOS 스토어 스크린샷 · 2026-10-22

현재 Flutter 화면을 iOS 플랫폼 설정으로 다시 렌더링했다. iPhone과 iPad 화면은 서로 다른 폭으로 별도 제작했다.

2026-10-23에는 5번 하단에 자외선 알림 예시를 추가해 총 5개로 구성했다. iPhone·iPad의 카드 비율과 하단 안내 여백을 맞췄고, 나머지 7장씩은 유지했다. 미리보기와 등록용·통합 ZIP에도 반영했다.

## 실제 위젯·타임라인 후속 갱신

pull로 반영된 코드를 기준으로 2번 타임라인을 다시 렌더링하고, 3번 위젯·4번 다크모드에는 실제 WidgetKit 홈 위젯 촬영본을 사용한다. 각 플랫폼의 나머지 5장은 기존 바이트를 유지한다. 새로고침 표시 18pt·터치 영역 44pt, 큰 위젯 브리핑 중앙 정렬, 준비물과 최저/최고 표시를 실제 화면에서 확인한다.

위젯 촬영은 전용 시뮬레이터(iPhone 15 Pro Max/iOS 17.5, iPad Pro 13형 M4/iOS 18.6)와 독립 촬영용 호스트 앱을 사용한다. 앱에 현재 `WeatherCareWidget.swift`·`WidgetRefreshIntent.swift`와 실제 폰트/아이콘을 그대로 포함하고, SpringBoard에 확장을 추가해 소형·중형·대형을 라이트/다크로 촬영한다. iPhone·iPad의 원본은 각각 별도로 촬영했다. 제작용 예시 날씨를 사용하며 실제 사용자 기기의 설정·위치·권한은 변경하지 않는다. 원본 크롭과 해시는 `native-ios-20261022/`에 보관한다. 전체 홈 화면 원본·접근성 트리·XCTest 결과는 ignored `build/ios-native-widget-20261022/`에 보존한다.

원본 크롭에서 실제 위젯 바탕색이 시작하는 경계 밖의 홈 배경만 투명하게 처리했다. 위젯 내부의 불투명 픽셀이 원본과 동일함을 검사한다. 스토어 이미지에는 비율 유지 확대·축소와 그림자를 적용하며 UI를 다시 그리거나 재색칠하지 않는다. 위젯을 재현하던 이전 Python 그리기 경로는 iOS 생성기에서 제거했다.

## 제작 기준

앱 화면은 현재 실제 MainTab·ExtraTab·WeekTab·SettingsScreen을 가져온 비표시 렌더링이다. 실기기나 시뮬레이터 촬영은 아니다. iPhone 440×956을 3배, iPad 1032×1376을 2배로 렌더링했다. 최신 준비물 카드·상단 여백·타임라인·심화 정보·알림 스위치 UI를 반영했다. 화면은 비율을 유지해 배치하며 한글 SUITE 글꼴과 실제 준비물 자산을 사용한다.

날씨·비교 수치·관측소·스위치는 제작용 예시이며 실제 현재 관측이나 사용자 설정이 아니다. 위젯은 위 후속 갱신에 따라 실제 WidgetKit 촬영본을 사용한다. 다양한 알림은 현재 지원하는 알림 종류의 예시 카드이며 이미지에 예시임을 표시했다. 실제 푸시는 발송하지 않았다.

파란 배경·흰 제목·노란 주제 문구로 기존 Android 스크린샷과 시각 스타일을 맞췄다. Android 스크린샷과 그래픽·iOS 헤더·검색 결과 소재는 유지했다. 기존 iOS 9장 구성은 최신 8장 구성으로 교체하고 이전 파일은 앱의 ignored `build/ios-screenshots-backup-20261022`에 보관했다. 통합 ZIP의 iOS/iPad 항목도 갱신하며 나머지 항목의 바이트를 보존·검증한다.

사용자 화면에 창을 띄우거나 실제 설정·위치·권한을 바꾸지 않았다. 앱/서버 배포 및 App Store Connect 업로드는 수행하지 않았다.

[Apple 스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)의 iPhone 6.9형·iPad 13형 세로 크기를 사용했다.

## 다시 만들기

앱 루트에서 Flutter 3.47.4와 Pillow가 설치된 Python으로 실행한다.

```sh
flutter test --no-pub store/capture_ios_test.dart
python3 store/generate_ios_store.py
```

2·3·4번만 갱신하려면 실제 네이티브 촬영 원본을 준비한 뒤 아래를 사용한다.

```sh
flutter test --no-pub --dart-define=STORE_CAPTURE_SCREEN=timeline store/capture_ios_test.dart
python3 store/generate_ios_store.py --topics 02-timeline,03-widget,04-dark-mode
```

네이티브 촬영 도구와 절차는 `../native_ios_widget_capture/README.md`를 따른다.

5번 알림 예시만 갱신할 때는 `python3 store/generate_ios_store.py --topics 05-notifications`를 실행한다.
