# 날씨챙겨 App Store 헤더·검색 결과 소재

제작·규격 확인일: 2026-10-11. 기본 언어: 한국어.

| App Store Connect 등록 항목 | 등록 파일 | 이미지 규격 |
| --- | --- | --- |
| 헤더 | `header-3840x1646.png` | 3840×1646, 21:9 규격, RGB PNG |
| 검색 결과 | `search-results-1920x1280.png` | 1920×1280, 3:2, RGB PNG |

`weather-care-app-store-creative-assets.zip`에는 위 두 이미지와 이 안내만 포함한다. 압축을 풀어 PNG를 각각 해당 항목에 등록한다.

## 디자인과 문구

기존 스토어 소재의 파란 배경·흰 글자·노란 강조색을 이어갔다. 우산·겉옷·선크림이 담긴 가방과 해·구름·빗방울로 날씨에 맞춰 외출 준비를 돕는 기능을 표현했다.

- 헤더: **날씨에 맞춰 / 오늘을 챙겨요**. 보조 문구: **날씨 · 준비물 · 생활 알림**.
- 검색 결과: **오늘 날씨와 / 준비물을 한눈에**.

현재 제공하는 날씨·준비물·알림 기능을 바탕으로 제작했다. 화면 캡처가 아닌 브랜드 일러스트이며, 앱의 실제 화면은 기존 `screenshots/ios` 스크린샷으로 별도 등록한다.

## 등록 시 확인

1. App Store Connect에서 날씨챙겨 앱의 **헤더 및 검색 결과** 항목을 연다.
2. 한국어 현지화에 헤더·검색 결과 PNG를 각각 선택한다. 콘솔에서 에셋 보관함을 사용하는 경우 해당 이미지들을 업로드한 뒤 배치에 선택한다.
3. 콘솔 미리보기에서 글자·그림의 잘림과 작은 화면의 가독성을 확인한 뒤 심사 제출 절차를 진행한다.

두 PNG 모두 알파 채널과 투명도가 없다. 이 작업에서는 파일 제작·로컬 검수까지 완료했으며, 콘솔 등록·미리보기·심사 제출은 수행하지 않았다.

Apple은 헤더에 3840×1646 이미지, 검색 결과에 1920×1280~3840×2560의 3:2 이미지를 지원한다. 두 배치에 지원하는 5244×2950 공통 PNG 규격도 있으나, 이번 소재는 각 배치의 개별 규격으로 만들었다. 창작 소재는 iOS 27·iPadOS 27 이상에서 표시된다.

- [Apple 공식 창작 소재 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications)
- [Apple 공식 디자인 지침·미리보기 안내](https://developer.apple.com/app-store/asset-best-practices/)

## 원본과 재출력

내장 `image_gen` 도구로 제작하고 시각 검수했다. 최종 생성 원본은 `source/header.png`(1915×821)와 `source/search-results.png`(1536×1024)에 보관했다. `export_assets.py`에서 Lanczos 리샘플링으로 등록 해상도로 확대하고 RGB PNG로 저장한다. 이 과정에서 새 그림·문구를 추가하거나 그림을 잘라내지 않는다. 생성 원본보다 해상도를 확대했으므로 네이티브 4K 생성 원본은 아니다.

최종 제작 프롬프트와 수정 프롬프트는 `제작_프롬프트.md`에 기록했다. Python과 Pillow가 있는 환경에서 `export_assets.py`를 실행하면 PNG 규격 및 ZIP 무결성을 확인하면서 다시 출력할 수 있다.
