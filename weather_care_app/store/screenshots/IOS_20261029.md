## Android 기준을 반영한 배치

Android와 같은 파란 배경·흰 제목·SUITE Heavy를 사용한다. 제목 크기는 너비 1080px 기준 60px, 두 줄 사이 간격은 16px다. 바깥 최소 여백과 제목·이미지 사이 간격은 같은 기준으로 72px이며 실제 iPhone에서는 88px, iPad에서는 138px로 비례 적용한다. 그림자는 바깥 여백과 제목 사이 간격을 침범하지 않는다.

앱 이미지는 남은 영역 안에서 최대한 크게 배치하며 원본의 비율과 전체 화면을 유지한다. iOS의 등록 종횡비가 Android와 달라 iPhone은 아래쪽, iPad는 좌우에 추가 여백이 생긴다. 화면을 늘리거나 일부를 잘라 여백을 채우지 않는다. 위젯은 세 크기의 상대 비율을 유지하고 남은 세로 높이에 맞춰 배치한다. 다크모드는 실제 대형 위젯을 함께 배치한다. 알림 예시는 최신 Android의 커진 글씨와 줄바꿈을 적용한다.

## 촬영과 보존

최신 제품 코드를 Flutter 3.47.4의 일반 `lib/main.dart`로 빌드하고, 전용 iPhone 15 Pro Max / iOS 17.5 시뮬레이터에서 XCTest로 실제 앱을 조작해 촬영했다. 별도 Simulator 창은 열지 않는다. 날씨 수치·날짜·화면은 합성하거나 수정하지 않고 앱의 실제 서버 응답과 촬영용 지역 설정을 사용한다.

앱 원본 1290×2796에서 상태바 177px와 홈 표시 영역 102px만 제외한다. 나머지 1290×2517과 화면 안의 탭·뒤로가기·메뉴는 그대로 보존한다. 위젯 제품 코드는 pull 전후 변경이 없어 10월 28일 실제 WidgetKit 촬영본 6개와 해시를 재사용했다. 앱 화면과 위젯의 날짜·시각·수치 차이는 각 원본 촬영 시점의 차이다.

5번은 기능 소개용 예시 카드이며 실제 푸시 수신 화면이 아니다. iPad 등록 이미지는 동일한 iPhone 앱·위젯 원본을 사용한 소개 이미지이며 iPad 직접 촬영본이 아니다. Android 이미지·도구·전용 ZIP과 기존 날짜의 iOS ZIP은 보존한다. 사용자 기기·권한·서버·스토어 배포는 변경하지 않는다.

원본 PNG·접근성 트리·명령 기록·빌드/XCTest 로그·소스 해시는 ignored `build/ios-live-store-20261029/`에 있다. 다시 생성하려면 앱 루트에서 실행한다.
