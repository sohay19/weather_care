# Google Play 백그라운드 위치 권한 시연 영상

촬영일: 2026-10-23. 기기: Samsung Remote Test Lab SM-S741N, Android 17.

## 전달 파일

- `권한심사_백그라운드위치_30초.mp4`: 한글 설명 자막이 포함된 30초 세로 영상. 실제 기기의 Android 화면 녹화를 편집했다. 음성 설명은 없으며 무음 오디오 트랙을 포함한다.
- `실기기_촬영_원본.zip`: 편집에 사용한 화면 녹화 3개. 촬영 대기와 점검 중 오류 화면도 원본 그대로 포함하므로 제출용 편집본과 구분한다.
- `촬영_편집_검증.json`: 촬영 조건, 각 장면의 원본과 사용 구간, 원본·최종 파일 SHA256.

## 영상 구성

| 구간 | 실제 화면 |
|---|---|
| 00:00–00:08 | 앱의 ‘백그라운드 위치 사용 안내’: 앱 미사용 중 위치 수집, 서버 전송, 날씨 알림 지역 갱신, 중지 방법 |
| 00:08–00:16 | Android 위치 권한에서 ‘앱 사용 중에만 허용’ → ‘항상 허용’ 선택 |
| 00:16–00:22 | 앱을 홈으로 내린 상태의 실제 ‘백그라운드에서 위치 갱신 중’ 실행 알림 |
| 00:22–00:30 | 실제 FCM으로 수신한 ‘현재 위치 날씨 알림 · 시연’, 지역명 경상북도 구미시 |

앱 화면·시스템 권한·알림을 합성하거나 다시 그리지 않았다. 원본 화면 전체를 유지하고 화면 바깥에 제목과 설명 자막만 추가했다. 여러 촬영 구간을 이어 붙였으며 실제 대기 시간을 줄였다.

## 시연 조건과 확인 범위

- 제품 소스 수정 없이 최신 Debug 앱 `1.1.0+26102302`를 사용했다. 연결 대상은 시험 서버다.
- 리모트랩 기기의 실제 앱을 사용했다. 물리적 이동 대신 별도 임시 도구로 Android GPS 시험 위치를 입력했다. 서버 알림 기준 격자가 서울 `[60,127]`에서 구미 `[85,96]`로 변경되는 것을 확인했다.
- 푸시는 자연 발생한 기상 경보가 아니다. 촬영 기기의 시험 설치 한 대에만, 갱신된 등록 지역을 조회하여 기존 서버 FCM 전송 함수로 시연 알림을 수동 발송했다. 알림 제목·본문과 영상 자막에 시연임을 표시했다.
- 2026-10-23 16:38:27 KST에 FCM HTTP 200 전송을 확인했고 실제 기기의 알림 창에서도 수신을 확인했다. 일반 사용자나 다른 설치에는 발송하지 않았다.
- 촬영 후 GPS 모의 사용을 해제하고 임시 위치 시연 도구를 제거했다. Wi-Fi는 변경하지 않았다. 리모트랩 예약은 사용자가 계속 사용할 수 있도록 종료하지 않았다.

## 제출 전에 필요한 조치

**촬영 당시에는 운영 서버의 앱 등록 호환성 문제가 있었다.** Release 앱이 `locationMeasuredAt`을 포함하면 운영 API가 `400 INVALID_INSTALLATION`으로 거절했고, 해당 항목을 제외하면 200, 시험 서버에서는 포함해도 200임을 별도 임시 설치로 확인했다. 점검용 임시 설치는 삭제했다.

촬영 작업에서는 운영 서버를 수정하거나 배포하지 않았다. 촬영 중 시험 앱의 일부 날씨 조회에서도 자료 준비/연결 오류가 발생했으며, 그 화면은 제출용 편집본에 포함하지 않았다.

이후 2026-10-23 운영 전체 승격으로 등록 호환성 문제를 해소했고, 인증 날씨 조회 오류도 양쪽 서버에서 수정했다. 17:35 KST 실제 API120건 점검에서 위치 측정 시각을 포함한 등록·설정 저장·백그라운드 위치 갱신·날씨 조회가 정상임을 확인했다. 자세한 결과는 저장소의 `docs/DB분리_조회기능_재점검_20261023.md`에 있다. 영상은 촬영 당시 시험 앱을 사용했으므로 제출할 실제 배포본의 기기 동작을 별도로 확인해야 하며, 이 영상만으로 심사 승인을 보장하지 않는다.

이 영상은 앞서 작성한 신고 문구의 **‘현재 위치 기반 날씨 알림’ 한 가지 기능**에 대응한다. YouTube 업로드와 Play Console 제출은 수행하지 않았다. 업로드한 영상이 심사 담당자에게 접근 가능한지 확인한 뒤 링크를 입력한다.

공식 기준: [Google Play 백그라운드 위치 권한 안내](https://support.google.com/googleplay/android-developer/answer/9799150?hl=ko).
