# Apple Watch 실제 실행 화면

2026-11-03 전용 Apple Watch Series 10 42mm / watchOS 11.5 시뮬레이터에서 촬영했다. 연결된 iPhone 16 Pro / iOS 18.6에서 앱의 실제 UI로 구로구 구로1동을 선택하고 운영 날씨를 조회했다. 날씨 자료를 합성하거나 주입하지 않았다. 시안 PNG와 별개인 제품 실행 캡처다.

자료 기준시각과 오른쪽 상단 시스템 시계는 다르다. 긴 상세는 Digital Crown 또는 세로 스크롤로 하단까지 읽는다. 사용자 데스크톱 전환 없이 XCTest와 simctl로 후반 검증·촬영했다.
