# 남은 하루 준비물·아침 알림 서버 선배포

2026년 10월 26일 **10:25:13 KST**에 시험 검증 후 운영 반영을 완료했다. 앱 빌드·설치·배포는 진행하지 않았다.

## 적용 내용

- 준비물과 정기 아침 요약이 현재부터 한국시간 오늘 자정까지의 예보를 사용한다. 저녁 비·눈도 아침부터 준비하며 우산을 먼저 표시한다.
- 날씨 항목마다 대표 물품을 먼저 배치한 뒤 남는 칸에 추가 물품을 배치한다. 한 항목이면 같은 항목 최대3개, 두 항목이면2+1개, 세 항목 이상이면 우선순위가 높은 세 항목에서 하나씩 제공한다.
- 준비물별 시작/종료 시각과 시간대별 목록을 제공한다. 기존 앱도 다음 날씨 조회부터 하루 목록·우선순위·배분을 사용하며, 타임라인 경계에서 끝난 물품을 제거하고 다음 물품을 표시한다.
- 알림은 같은 하루 정책으로 최대3개를 요약하며 대표 안개 안내가 우산 안내를 대체하지 않는다. 다음 정상 발송부터 적용되고, 오늘 이미 발송한 아침 요약을 다시 보내지 않는다.
- 앱의 진행 중 ‘n시부터’ 유지와, 시간 경과로 새로 등장한 물품의 시작 표시 보완은 사용자가 앱 업데이트로 적용한다.

## 배포 범위

실제 실행 중이던 소스 171개를 환경별로 내려받아 아래 **7개 파일의 필요한 부분만** 수정했다. 나머지 소스는 파일 전체 SHA256이 이전과 같다. 이 후보는 최신 전체 커밋 `d44a0c5` 자체를 배포한 것이 아니다.

- `src/api/weather.ts`
- `src/notification/notificationBuilder.ts`
- `src/notification/notificationScheduler.ts`
- `src/presentation/weatherBrief.ts`
- `src/recommendations/preparationPolicy.ts`
- `src/recommendations/recommendationEngine.ts`
- `src/types.ts`

로컬의 별도 꽃가루 마스크·대기정체 환기·적설 이력/그래프·동파 작업과 이전 미배포 준비물 근거 기능은 포함하지 않았다. 운영과 시험의 기존 주간 응답 차이도 유지했다. 운영에는 새 `upcomingDays`가 여전히 없고 시험에는 기존 필드가 유지된다.

- 운영 실행 경로: `/opt/weather-care/releases/20261023-full-production/weather_care_server`
- 시험 실행 경로: `/opt/weather-care/releases/20261023-full-test/weather_care_server`
- API 두 개와 운영 스케줄러를 재시작했다. 스케줄러의 정상 시작 이벤트까지 확인했다.
- 패키지/잠금 파일·DB 경로/스키마·환경 및 수집 설정·서비스 정의·터널 설정을 변경하지 않았다. 실제 사용자 자료에 직접 쓰거나 마이그레이션·수동 선수집·수동 푸시를 실행하지 않았다. 스케줄러의 기존 시작 절차와 정기 작업은 유지된다.

## 검증 결과

- 운영/시험 실제 소스 기반 후보 전체 TypeScript 검사 통과.
- 후보의 준비물·브리핑·Today API·알림 스케줄러·목적지·강수 구간 관련 102개 검사 통과.
- 후보가 생성한 JSON을 수정 전 앱 소스에 입력하는 호환 검사1개 통과. 모든 과거 설치 바이너리/실기기를 검증했다는 의미는 아니다.
- 실제 서버의 런타임/의존성으로 하루 준비물·1/2/3항목 배분·강수 시작/종료·타임라인 교체·안개와 저녁 비 알림6종을 후보와 설치 후 소스에서 확인했다. 이 검사는 합성 자료만 사용하며 FCM을 발송하지 않는다.
- 운영/시험 배포 전후 공개 HTTPS 24건 모두200: health, Main, 구형 Today, PREPARATION_18 Today, 위젯, 주간 응답. 기존 최상위 필드/자료형과 주간 필드 차이를 보존하고 새 preparationPeriods를 확인했다.
- 두 실제 소스 트리가 각각 후보의 전체 SHA256 manifest와 일치함을 확인했다. 환경 설정 파일의 해시와 사용자/공용 DB의 스키마 해시도 유지했다.
- 최종 서비스: 운영 API PID701484, 운영 스케줄러 PID701547, 시험 API PID701329, 모두active.
