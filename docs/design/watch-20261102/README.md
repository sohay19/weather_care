# 날씨챙겨 워치 디자인 시안 0.8

- `index.html`: 클릭 가능한 시안. 로컬 브라우저에서 열면 된다. 폰트와 아이콘을 내장해 외부 서버 없이 표시한다.
- `overview.png`: 챙겨요→현재 날씨→타임라인→기상/생활 순서와 체크/지표 상세 예시6화면.
- `widgets.png`: 소형·대형 Wear 위젯, 기존 타일, 컴플리케이션 배치 예시.
- `prototype.png`: 데스크톱 검토 화면, `mobile-preview.png`: 좁은 브라우저 검토 화면.
- `screens/`: PDF에 쓰는 원형 화면별 이미지.
- `device-summary.json`: 연결 워치 속성 읽기 확인 집계. 기기 식별번호·계정 정보는 기록하지 않았다.
- `verification.json`: 체크/상세/화면 이동/위젯 구성 등28개 점검. Wear OS 앱 실행 검사가 아니다.
- 상세 기획: `../../워치앱_위젯_기획서_20261102.md`.
- PDF 기획·디자인: `../../../output/pdf/watch-app-plan-20261102.pdf`.

0.6 PDF는9페이지다. 챙겨요 우측 체크 전/후, 작아진 어제 비교 영역, 타임라인 명칭, Today형2열 지표의 스크롤 구간/상세를 반영했다. 소형은 준비물 없이 위치·기준시각/기온·체감·작은 날씨/최저최고, 대형은 같은 날씨 정보에 준비물 아이콘3개를 더했다. 기존 타일은 기온+날씨아이콘과 짧은 브리핑, 워치페이스는좌기온/우날씨아이콘이다.

모든 날씨·위치·특보는 합성 예시다. 워치 앱이나 위젯 서비스가 설치된 실제 화면이 아니다. 시안의 위젯 외곽은 OEM 컨테이너 예시이고, 컴플리케이션 외형은 사용자가 고른 워치페이스가 결정한다. UI를 확인하기 위해 Windows 창을 열지 않고 별도 headless 브라우저로 렌더링했다. 워치에는 읽기 전용 ADB 조회만 수행했다.

기존 SUITE 폰트와 준비물 자산을 사용했다. 어두운 아이콘은 명도 조정했으며, 립밤은 시안용 대체 벡터다. 반복 검토를 위한 생성·렌더링 도구도 같은 폴더에 보존했다. 도구의 실행 경로는 현재 Windows 환경 기준이며 앱 제품 코드의 일부가 아니다.

0.6: 앱 위젯 날씨 아이콘PNG를 그대로 내장했다. 소형·대형은 좌측기온+날씨/우측체감의 개별배경, 대형의 각 준비물은 원형배경이다. 기존타일은 같은크기·같은행 기온/날씨와 중앙한줄브리핑으로 수정했으며, 탭은워치앱현재날씨로 연결된다.

0.6: 어제 비교의 둘째 줄을 체감 차이 문구로 교체하고 챙겨요/기상생활 하단은 총 n개 · 아래로로 통일했다. 소형/대형은청록박스·22dp작은아이콘·세로중앙기온/아이콘·작은라벨의한줄체감, 타일은제목아래지역/기준시간과하단최저최고를추가했다.

0.6: 현재날씨기온/아이콘도세로중앙,소형/대형은아이콘→기온순서로교체했다. 기본바탕검정,기온/날씨·체감·준비물개별배경은이전전체바탕색#253747이다. 타일의기온·날씨·브리핑묶음은21dp내려지역/기준시각과최저최고사이에세로중앙배치했다.

0.6: 소형/대형최저최고를같은원형화면중앙하단(x104/y187)에배치했다. 기존타일기온·날씨·브리핑묶음은0.5시안보다8dp상향했다.
