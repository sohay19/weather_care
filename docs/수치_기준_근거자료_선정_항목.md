# 수치 기준 근거자료 선정 항목

- 기준일: 2026-08-21
- 적용 범위: 날씨 판단, 생활 행동, 브리핑, 화면·알림 출력
- 목적: 개별 임계값을 임의로 정하기 전에 적용할 공식 문서, 행정 기준, 국내외 연구와 한국인 대상 연구를 선정한다.

## 1. 문서 사용 원칙

- 이 문서는 구체적인 임계값을 확정하는 문서가 아니라 **근거자료를 선정해야 하는 항목의 전체 목록**이다.
- 각 항목은 우선 적용할 공식 기준과 이를 보완할 연구자료를 구분해 기록한다.
- 공식 기준이 여러 개면 서비스 대상, 계절, 지역, 연령과 사용 상황을 기준으로 적용 범위를 정한다.
- 한국인의 체감이나 생활 행동을 다루는 항목은 가능하면 한국인 대상 연구를 우선 검토한다.
- 기준을 채택할 때 문서명, 발행기관, 버전·시행일, 대상 집단, 적용 범위와 예외를 함께 기록한다.

## 8. 현재 미연결 출력의 근거자료 선정 항목

아래 출력은 문구 카탈로그에는 있지만 아직 생성 규칙이 없거나 일부 상황만 연결되어 있다. 각 출력에 대해 다음 근거 범위를 먼저 선정한 뒤 수치, 지속시간, 해제조건과 알림 방식을 정한다.

| 출력 항목 | 선정해야 할 근거 범위 | 추가로 정할 적용 조건·데이터 |
| --- | --- | --- |
| 반려동물 산책 시간 | 동물 종·크기·나이·질환별 온열·한랭 위험, 노면 열 위험, 자외선·강수·풍속·PM·오존 노출, 적정 운동시간 | 일반 안내와 개체별 안전 안내의 구분, 최소 산책 가능시간, 추천 시간대 길이, 반려동물 프로필과 노면온도 데이터 필요 여부 |
| 빨래 걷기 마감시간 | 강수 시작 예측, 강수확률·강수량, 습도 상승, 풍속 변화, 실외건조 연구·생활지침 | 첫 강수 전 안전 여유시간, 예보 변동 허용범위, 사용자의 빨래 시작·널기 상태, 마감시간 갱신·취소 조건 |
| 우산 말리기 알림 | 강수 종료 판단, 우산 건조·곰팡이·위생 관련 생활지침, 습도와 환기 조건 | 우산 사용 여부의 판단 방법, 비·눈의 양과 지속시간, 알림 지연시간·반복 여부, 강수 추천 기록을 사용 상태로 볼 수 있는지 여부 |
| 꽃가루·알레르기 주의 | 국내 꽃가루 지수·달력, 수종·잡초별 계절성, 지역별 농도, 알레르기 민감군 행동지침 | 사용할 Provider와 갱신주기, 사용자 알레르기 유형, 주의 단계와 예보 범위, 결측·비지원 지역 처리 |
| 호흡기 주의 | PM10·PM2.5·오존의 일반·민감군 기준, 기온·습도·한랭과 호흡기 증상 연구, 복합노출 지침 | 일반 사용자와 호흡기질환자 분리, 오염물질 복합 시 우선순위·가중 방식, 마스크 준비와 야외활동 제한 출력의 구분 |
| 수도관 동파 주의 | 기상청·지자체·상수도기관 동파 단계, 최저기온과 지속시간, 풍속·노출·건물 및 배관 조건 | 사전 알림시간, 야간 최저값과 시간대별 값의 선택, 공동주택·단독주택·외부배관 구분, 지역·건물정보가 없을 때의 보수적 출력 범위 |
| 세차하기 좋은 날 | 강수 없는 지속시간, 세차 후 건조시간, 황사·PM·꽃가루 재오염, 결빙·고온·강풍 조건, 세차 관련 생활지침 | 세차 전후 무강수 범위, 당일과 며칠 전망의 구분, `좋음`과 `미루기`의 해제조건, 실내·자동세차 예외 |
| 오존 자체 위험 안내 | 국내 오존 등급·주의보·경보, 일반·민감군 야외활동 지침, 시간대별 노출과 고온·PM 복합위험 | 실시간 관측과 예보의 구분, 현재값만으로 안내할 범위, 지속시간과 해제조건, 데이터 신선도·측정소 대표성, 호흡기 주의와의 중복 처리 |

데이터 준비 관점에서는 다음과 같이 구분한다.

- 현재 날씨·시간별 예보·에어코리아 데이터로 설계 가능한 항목: 호흡기 주의, 수도관 동파 주의, 세차하기 좋은 날, 현재 오존 위험 안내
- 기존 데이터에 사용자 상태 또는 프로필이 필요한 항목: 반려동물 산책 시간, 빨래 걷기 마감시간, 우산 말리기 알림
- 새 외부 데이터가 필요한 항목: 꽃가루·알레르기 주의, 예보형 오존 위험 안내, 정확한 노면온도를 사용하는 반려동물 산책 안내
