# Main 한 줄 브리핑 문구 기획

## 1. 역할 정의

Main의 브리핑은 기온과 날씨를 다시 읽어주는 영역이 아니다. 숫자와 상태는 바로 아래 카드에서 확인하고, 브리핑은 **오늘의 장면과 작은 행동을 먼저 떠올리게 하는 문장**을 담당한다.

- 직접 표현하지 않음: 기온·온도·도·맑음·흐림·비·눈·강수·습도·풍속·자외선·미세먼지와 수치
- 사용할 수 있음: 시간대, 우산·그늘·옷깃·겉옷·마스크·물병 같은 생활 사물, 빛·공기·발걸음 같은 감각적 단서
- 안전상 중요한 정보는 감성 문장에 숨기지 않고, 색이 적용된 TODO와 상세 수치에서 명확히 전달

## 2. 문장 생성 구조

날씨값 하나를 문장 하나에 바로 연결하지 않고, 서버가 먼저 `오늘의 장면(scene)`을 결정한 뒤 장면별 문구 카탈로그에서 문장을 고른다.

1. **변화 탐지**: 현재값과 오늘 시간대별 데이터에서 대표 상황을 찾는다.
2. **대표 장면 선택**: 이동 안전과 준비물 필요성을 기준으로 7개 장면 중 하나를 고른다.
3. **템플릿 선택**: 날짜·지역 격자·장면 코드를 사용해 해당 장면의 완성형 템플릿을 고른다.
4. **슬롯 조합**: `시간대 + 행동/준비 + 생활 효과` 세 슬롯을 각각 검수된 10개 후보에서 선택한다.
5. **품질 검증**: 직접 날씨 표현, 미해결 슬롯, 중복 후보, 길이 초과를 단위 테스트로 차단한다.

### 대표 장면 우선순위

1. `CAREFUL_STEPS`: 발걸음 주의가 필요한 상황
2. `WET_TRAVEL`: 우산 준비가 필요한 상황
3. `MASK_READY`: 마스크 준비가 필요한 상황
4. `SHADE_BREAK`: 그늘·양산·물병이 유용한 상황
5. `LAYER_READY`: 겉옷 한 겹이 유용한 상황
6. `STEADY_PACE`: 소지품과 이동 속도를 살필 상황
7. `DAILY_RHYTHM`: 특별한 준비보다 평소 리듬이 어울리는 상황

대표 장면 하나만 사용해 여러 정보를 억지로 한 문장에 섞지 않는다. 나머지 정보는 TODO에서 이어서 보여준다.

## 3. 뻔함과 반복을 줄이는 장치

- 완성형 템플릿은 전체 20개이며, 7개 장면에 2~3개씩 배치한다.
- 모든 템플릿은 정확히 3개 슬롯을 사용하고, 각 슬롯 풀은 중복 없는 후보 10개를 갖는다.
- 공통 시간 슬롯 1개와 장면별 행동·효과 슬롯 14개로 총 15개 슬롯 풀을 운용한다.
- 이론상 `20개 템플릿 × 슬롯 조합 1,000개`로 최대 20,000개 문장 조합을 만들 수 있다. 시간 슬롯은 실제 발생 시간대에 맞춰 선택하므로 무작위 사실 왜곡은 없다.
- 같은 날짜·지역·장면에서는 항상 같은 결과를 반환해 새로고침 때 문장이 바뀌지 않는다.
- 날짜별 순환값을 템플릿과 행동·효과 슬롯에 더해 같은 문장 전체가 7일 안에 반복되지 않도록 한다.
- 2단계에서는 D1에 지역별 최근 `templateId`를 저장해 실제 노출 이력을 기준으로 중복을 막는다.
- “좋은 하루”, “기분 좋은”, “포근한 하루”처럼 어디에나 붙일 수 있는 범용 문구는 카탈로그에서 제외한다.

런타임 생성형 AI보다는 검수된 카탈로그를 우선한다. 결과가 예측 가능하고, 기상 사실과 어긋나는 표현을 테스트로 차단할 수 있으며, 응답 지연도 늘지 않는다.

## 4. 문구 규칙

- 최대 길이: 최장 슬롯 조합 기준 47자, 한 문장, 화면에서는 최대 3줄
- 한 문장에 생활 사물은 1개만 사용
- 과장된 감정이나 불안을 유도하는 표현은 사용하지 않음
- 지역명은 헤더에 있으므로 브리핑에서 반복하지 않음
- 같은 의미의 형용사를 연달아 쓰지 않음
- 직접적인 사실을 제거하더라도, 실제 데이터에서 도출할 수 없는 장면은 만들지 않음

## 5. 예시 카탈로그

| 내부 장면 | 사용자에게 보이는 문구 예시 |
| --- | --- |
| `WET_TRAVEL` | 오늘 퇴근길, 작은 우산 하나면 돌아오는 길이 든든해져요. |
| `CAREFUL_STEPS` | 아침 일찍엔 발끝을 천천히 디디면 목적지까지 차분히 닿아요. |
| `MASK_READY` | 오늘 출근길, 가벼운 마스크를 챙기면 바깥 호흡이 한결 편안해져요. |
| `SHADE_BREAK` | 한낮엔 그늘이 이어진 길을 고르면 바깥 일정에 쉴 틈이 생겨요. |
| `LAYER_READY` | 저녁때엔 가벼운 겉옷을 한 겹 더하면 늦은 귀가에도 든든함이 남아요. |
| `STEADY_PACE` | 오후 한때엔 모자와 소지품을 살피면 바깥 걸음이 단정해져요. |
| `DAILY_RHYTHM` | 오늘 오전 중, 미뤄둔 산책을 꺼내면 하루의 리듬이 부드럽게 이어져요. |

## 6. 서버 데이터와 응답

`buildWeatherBriefResult()`는 화면 문자열 외에 다음 메타데이터를 반환한다. 현재 Today API에는 기존 계약을 유지하기 위해 `text`만 `brief` 필드로 전달한다.

- `scene`: 선택된 대표 장면
- `templateId`: 실제 사용한 카탈로그 문구
- `slots`: 실제 사용된 시간·행동·효과 문구
- `catalogVersion`: 배포된 문구 카탈로그 버전

이 값은 문구가 실제 예보와 맞지 않을 때 원인을 재현하고, 반복률을 측정하는 데 사용한다.

## 7. 수용 기준

- 기온·날씨 직접 표현과 숫자가 결과에 포함되지 않는다.
- 동일 지역에서 새로고침해도 같은 날짜·장면이면 문구가 유지된다.
- 같은 완성 문장이 7일 안에 반복되지 않는다.
- 문구의 장면이 실제 입력값과 일치한다.
- 최장 조합도 47자와 앱 최대 3줄을 만족한다.
- 위험 정보가 감성 문구에만 존재하지 않고 TODO 또는 수치에도 반드시 노출된다.

## 8. 구현 순서 제안

1. [완료] 단일 조건문을 7개 장면 선택기와 20개 템플릿 카탈로그로 분리
2. [완료] 15개 슬롯 풀에 각각 10개 후보 추가
3. [완료] 날짜·지역 기반 결정적 선택, 7일 문장 순환, 금칙어·길이 단위 테스트 추가
4. [후속] 운영 노출 데이터를 본 뒤 D1 기반 실제 노출 이력 저장과 통계 추가
