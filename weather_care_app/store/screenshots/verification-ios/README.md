# iOS 위젯 실제 캡처 및 확인

- 기기: iPhone 18 Pro 시뮬레이터, iOS 27.0 / Xcode 27.0.
- 최신 소스의 앱과 WidgetKit 확장을 시뮬레이터용으로 빌드·설치한 뒤 실제 홈 화면을 캡처했다.
- 경기도 이천시 호법면은 이번 촬영에서 앱의 지역 선택 화면으로 선택한 지역이다. 실제 서버 자료를 사용했으며 날씨 수치·UI를 생성하거나 재색칠하지 않았다.
- `small-dark.png`: 지역명 아래 기준시간. 원본 `small-large-dark-home.png`의 (80,270,572,762) 영역.
- `medium-dark.png`: 새로고침 버튼 왼쪽 기준시간. 원본 `medium-large-dark-home.png`의 (80,270,1128,762) 영역.
- `large-dark.png`: 새로고침 버튼 왼쪽 기준시간. 같은 원본의 (80,873,1128,1968) 영역.
- 원본은 모두 1206×2622 PNG. 위젯별 파일은 원본을 크롭한 RGB PNG이며 크기·비율·색상을 변경하지 않았다.
- 세 크기의 다크모드와 중형·대형의 라이트모드에서 버튼 주변 큰 원형 경계가 없는 것을 확인했다. 컨테이너 자체의 시스템 외곽 경계는 버튼 경계와 별개다.
- 대형 중앙 및 세 크기 각각의 44pt 터치 영역 좌상단 약 10% 지점을 눌렀다. 앱을 열지 않은 홈 상태에서 App Group snapshot의 receivedAt이 아래 기록처럼 갱신됐고 refresh_status는 비어 있었다.
- 기존 native_startup_defaults_test 6개 통과, Xcode 시뮬레이터 빌드 성공. 실기기·iPad 네이티브 렌더링은 이번에 검증하지 않았다.
- 촬영 완료 후 시뮬레이터 외형 설정을 처음의 라이트모드로 복원했다. 커밋·푸시·스토어 업로드 없음.
