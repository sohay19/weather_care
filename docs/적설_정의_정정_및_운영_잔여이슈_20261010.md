# 적설 정의 정정과 운영 잔여 이슈

2026년 10월 10일 기준으로 앱의 적설 관련 용어를 정정하고, 마지막 운영 릴리스 `20261009-collection-recovery-v2`를 점검했다. **앱에서 적설량은 기존 눈까지 포함해 현재 지면에 쌓인 눈의 수직 깊이(cm)를 뜻한다.** 예보 신적설이나 하루 최심신적설을 현재 적설량으로 표시하지 않는다.

데이터 점검 대상은 한국 시각 **2026-10-01 이후**다. 2026년 행정경계 승인 대기와 공공데이터포털 운영계정 신청 대기는 이번 잔여 이슈 목록에서 제외한다. 10월 이전의 작년 비교 자료를 복원할 필요는 없다. 이는 모든 10월 자료가 이미 저장됐다는 의미나 기존 72시간 실황·7일 일관측 보관 정책을 월 전체 보관으로 바꾼다는 의미가 아니다.

## 적설 항목의 계약

| 항목 | 의미와 단위 | 원본 | 앱 표시와 적용 상태 |
|---|---|---|---|
| 현재 적설량 | 이전에 내린 눈을 포함해 관측 시각에 지면에 쌓인 눈의 깊이, cm | `kma_snow1.php`, `sd=tot`, `snow=0` | 활용승인·실제 응답 검증 완료. 현재 앱·운영 수집 미연결. 일자료나 예보로 대체하지 않음 |
| 시간별 예상 신적설 | 해당 예보 1시간 동안 새로 쌓일 눈의 깊이, cm | 단기예보 `SNO` | 기존 `snowfallAmount`와 범주형 원문을 유지하고 `예상 신적설`로 표시 |
| 과거 최심신적설 | 하루 동안 새로 내린 눈이 가장 깊게 쌓였을 때의 깊이, cm | 현재 운영 `sfc_aws_day.php`의 `sd_day_max`; 별도 승인된 `kma_snow_day.php`의 `sd=day` | 관측 응답은 `최심신적설`로 표시. 두 출처를 섞어 덮어쓰지 않음 |
| 일 최심적설 | 기존 눈을 포함해 하루 중 가장 깊게 쌓였을 때의 깊이, cm | `kma_snow_day.php`, `sd=tot` | 현재 시각의 적설량으로 사용하지 않음 |

`SNO=0`, `SNO=NONE`, `적설없음` 원문은 해당 예보 구간에 새로 쌓일 눈이 없다는 뜻이다. 기존 눈까지 모두 녹았거나 현재 총 적설량이 0이라는 뜻으로 확대하지 않는다. `미만`·`범위`·`이상`은 기존 범주와 원문을 보존한다. `snowExpected` 역시 눈 예보 여부이지 현재 적설 유무가 아니다.

운영 일관측의 `snowfallAmount`는 호환 필드 이름을 유지하지만 의미는 일 최심신적설이다. `AVAILABLE`은 정상 수치(명시적 0 포함), `NO_RECORD`는 정상 응답에 수치 기록이 없음, `UNAVAILABLE`은 수집 실패다. 뒤의 두 상태는 0cm로 바꾸지 않는다. 적설 수치가 없다는 이유로 정상 기온·강수까지 결측 처리하지 않는다.

현재 적설 요청은 사용자 지정에 따라 `sd=tot&snow=0`을 사용한다. 저장된 `snow=0`·`snow=2` 응답은 원문까지 동일하며, 674지점 중 664지점은 명시적 0cm, 10지점은 결측 `-99.7`이었다. 이 결과를 모든 미래 회차의 완비 보장으로 확장하지 않는다. `snow=0`에서 지점이 빠졌다는 이유만으로 0cm를 만들지 않는다.

요청한 `tm`과 실제 관측 시각은 구분한다. 확인한 11:20·11:30 요청은 11:00 관측값을 반환했으므로, 응답 행의 `TM`을 적설 관측 시각으로 저장한다. 현재 적설은 시간별 신적설 합계나 하루 최댓값에서 계산하지 않는다. 유효한 현재 적설이 없으면 인근 유효 관측소를 사용하고 출처·거리·실제 관측 시각을 보존한다.

향후 현재 적설을 연결할 때는 예보·일자료와 구분한 필드, 실제 관측시각, 제공처, 관측소·좌표·GPS 기준 거리, 가용성과 신선도를 함께 보존해야 한다. 인근 유효 관측소 사용은 허용하지만 GPS 현장에서 직접 측정한 값이라고 표시하지 않는다. 아직 검증하지 않은 시각별 응답의 갱신·신선도 기준을 구현 완료로 취급하지 않는다.

## 이번 앱 수정

- 시간별 예보의 `쌓일 눈`을 `예상 신적설`로 정정했다. 결측 안내에도 같은 이름을 사용한다.
- Week의 `예상 강설`을 예보일에는 `예상 신적설`, `historical=true` 또는 `forecastSource=KMA_OBSERVATION`인 관측일에는 `최심신적설`로 구분했다.
- 앱과 서버 모델의 호환 `snowfallAmount`가 현재 총 적설량이 아님을 주석으로 명시했다. 수치와 기존 API 필드 이름은 변경하지 않았다.
- 과거 관측 표기, 원본 범주 유지, 미확보 값을 0으로 바꾸지 않는 동작을 회귀 검증한다.

현재 Main·Detail의 현재 날씨에는 총 적설값을 파싱·표시하는 계약이 없다. 이번 표기 정정으로 현재 적설 수집이 완성됐거나 승인된 일자료가 앱에 반영됐다고 해석하지 않는다. 앱 설치·배포와 서버 재배포는 이번 작업에서 수행하지 않았다.

## 정의·표기 정정 검증 결과

예보·관측의 눈 표기를 분리하고, 현재 적설값을 기존 `snowfallAmount`에서 만들지 않는 기준을 문서에 명시했다. 0과 미확보, 범주형 예보의 의미도 보존한다.

- 앱은 기존 로컬 수정에서 시간별·예보일 `예상 신적설`, 과거 관측일 `최심신적설`로 이미 구분되어 있어 이번 문서 정정에서는 추가 소스 변경을 하지 않았다.
- 관련 앱 테스트 `hourly_weather_test.dart`, `week_tab_test.dart`, `week_precipitation_test.dart` 54개가 통과했다. 모델·시간별 예보·Week 표시 파일 3개의 정적 분석 결과는 문제 0건이다.
- Word 명세 4개를 실제 PDF·PNG로 렌더링하고 총 72쪽을 검토했다. 추가한 정의 페이지의 줄바꿈·가독성과 전체 문서의 글자 깨짐·잘림을 확인했다.
- 문서 정의·표기 정정 작업에서는 서버 소스 수정, 제공처 재호출, 운영 배포와 커밋을 하지 않았다. 현재 적설 API의 정규 수집·앱 연결은 별도 미완료 항목이다.
