# Setting 데이터·권한 안내

확인일: 2026-09-11. 현재 코드의 기능 안내이며 법적 개인정보처리방침이 아니다.

## 화면 위치

- Setting 맨 아래의 9px 출처 문구를 읽을 수 있는 `데이터·권한 안내` 카드로 교체한다.
- 카드에서 `데이터 출처`, `위치 권한 안내`, `알림 권한 안내`, `저장·전송 정보 안내`를 각각 별도 화면으로 연다.
- 기준 지역 카드와 저장·기기 알림 상태 카드에도 해당 권한 설명을 바로 여는 버튼을 둔다.
- 전체 알림을 꺼도 안내는 열 수 있다. 읽기에는 인터넷·GPS·FCM 연결이 필요 없고, 화면을 여는 행위는 설정 변경·권한 요청·테스트 발송을 하지 않는다.
- 외부 기관 링크는 사용자가 누를 때만 기본 외부 브라우저로 연다. 열기 실패/예외에는 선택 가능한 주소와 복사 기능을 제공한다. 링크에는 위치·설치 식별자·API 인증값을 붙이지 않는다.

## 자료와 설명의 연결

| 자료 | 코드 근거 | 안내 핵심 |
| --- | --- | --- |
| 기상청 기온·바람·비·눈 예보 | `providers/weather/kmaWeatherProvider.ts`, 앱 `kma_direct_weather_service.dart` | 예상기온은 관측값이 아니다. 서버 연결 실패 시 일부 직접 조회 가능 |
| 기상청 자외선·특보 | `providers/uv/kmaUvProvider.ts`, `providers/warnings/kmaWarningProvider.ts` | 공식 자료와 내부 체감·활동 판단 구분 |
| 관측분석·레이더 | `providers/precipitation/precipitationObservationProvider.ts`, `notificationScheduler.ts` | 현재 비 알림은 두 자료 일치 조건. 격자 분석은 사용자 지점에서 실제 강수 확인을 보장하지 않음 |
| 에어코리아 미세먼지·초미세먼지·오존 | `providers/air/airKoreaAirQualityProvider.ts`, `environmentalDataService.ts` | 전국 GPS/격자 기준 가까운 측정소를 선택. 사용자 자리의 실측이 아니며 자료 미수신·결측 가능. [전국 조회 계약](./대기질_전국_조회.md) |
| 기상청 도로 결빙 가능정보 | `providers/road/kmaRoadIceProvider.ts` | 실제 결빙 확인이나 모든 도로 지원을 뜻하지 않음 |
| ITS 도로통제 | `providers/traffic/itsRoadControlProvider.ts` | 돌발정보에서 관련 통제 확인. 자료 없음은 안전 보장이 아님 |

기관명과 자료 종류는 실제 Provider로 확인했다. 공식 기관 사이트는 출처 확인용이지 앱에 표시된 개별 수치의 실시간 일치를 보장하는 링크가 아니다. 전국 지역 선택과 개별 자료의 전국 지원을 구분한다. 내부 판단·행동 문구의 수치·정책은 이번에 변경하지 않았다.

## 위치·알림·저장/전송 설명 근거

- `current_location_service.dart`, `home_screen.dart`: GPS 모드의 실행·복귀·새로고침·명시적 재확인, 명시적 권한 요청, 정밀/대략적 위치와 정밀 좌표 전송 조건. 백그라운드 연속 위치 추적은 하지 않는다. 수동 지역은 GPS를 읽지 않는다.
- `weather_service.dart`, `server_data_access.dart`: 인증된 등록 상태에서는 Today/Weekly 조회에 서버 설치 식별자와 격자, 정밀 조건이 충족된 Today 조회에 위경도를 전송한다. 삭제 중지 상태에서는 식별자·인증·정밀 좌표 없이 지역 격자를 조회한다.
- `notification_registration_service.dart`, 서버 `api/installations.ts`, `database/installationsRepository.ts`: 설치 식별자·격자·위치 모드·플랫폼·시간대·허용 시 FCM 토큰·정밀 조건 충족 시 좌표 등록. 서버는 최신 등록값을 저장한다. 등록 실패 시 이전 서버 정보가 남을 수 있다.
- `notification_permission_service.dart`, `settings_save_controller.dart`: OS 알림 권한과 앱 전체 알림·서버 저장은 별개. 권한 허용/저장 성공이 실제 수신을 보장하지 않음. 이번 설명은 기존 요청/새로고침/기기 설정 버튼을 대체하지 않는다.
- `installation_identity.dart`, `app_settings_repository.dart`, `preparation_checklist_repository.dart`: 설치 식별자·선택 지역·격자·알림 설정·준비물 체크 등을 기기에 저장한다.
- 서버 migrations 및 `notificationScheduler.ts`: 등록 정보·알림 설정·발송 상태·발송 이력 저장. 위치 권한 해제·알림 끄기만으로 저장 정보를 삭제하지 않는다. 원시 좌표 무저장, 완전 익명, 로그 미저장을 약속하지 않는다. 장기 미사용 설치와 발송 이력의 1년 자동 정리는 [보유기간 계약](./서버_데이터_보유기간.md)을 따른다.
- 앱 `pubspec.yaml`, `main.dart`: FCM, Firebase Analytics 패키지가 포함되어 있고 Google Mobile Ads가 초기화된다. 사용자 정의 Analytics 이벤트/광고 요청 UI가 없다고 SDK 자체의 정보 처리가 없다고 단정하지 않는다. 제공업체 안내를 별도로 연결한다.

## 외부 링크 및 구현 참고

- [기상청 날씨누리](https://www.weather.go.kr/w/index.do), [기상청 API허브](https://apihub.kma.go.kr/), [에어코리아](https://www.airkorea.or.kr/), [ITS 오픈데이터](https://www.its.go.kr/opendata/intro). ITS는 공식 검색 결과로 주소 확인했으나 리서치 도구의 본문 열기는 실패했다. 사이트 접근 성공을 보장하지 않으며 앱도 실패를 처리한다.
- [url_launcher 공식 문서](https://pub.dev/packages/url_launcher): 6.3.2 추가. `launchUrl` + `LaunchMode.externalApplication`으로 직접 시도하고 false/예외를 처리한다. `canLaunchUrl` 사전 조회나 추가 기기 권한은 사용하지 않는다. 기존 패키지는 업그레이드하지 않았다.
- [Firebase 데이터 처리 안내](https://firebase.google.com/support/privacy), [Analytics 데이터 수집 안내](https://support.google.com/firebase/answer/6318039?hl=ko), [Google 광고 서비스 안내](https://policies.google.com/technologies/ads?hl=ko).
- [Google Mobile Ads의 데이터 공개 안내](https://developers.google.com/admob/android/privacy/play-data-disclosure)는 SDK가 자동 처리할 수 있는 정보와 앱 개발자의 별도 점검 필요성을 설명한다. 문서는 최신 SDK 대상이므로 현재 설치 버전에 모든 내용을 그대로 확정 적용하지 않았다.

## 별도 확인이 필요한 항목

- 정식 개인정보처리방침: 운영 주체·문의/권리 행사 경로·보유/삭제 기준·외부 서비스/국외 처리 범위를 확인한 뒤 문서와 실제 공개 URL을 연결해야 한다. 이번 기능 안내가 이를 완료한 것으로 취급하지 않는다.
- Firebase/Google Ads 실제 운영 콘솔·동의·수집 설정과 설치 버전별 처리 항목, 앱스토어 공개 항목은 별도 검토한다. 설명을 이유로 수집 설정을 켜거나 끄지 않았다.
- `서버 내 나의 데이터 삭제` UI/API와 본인 확인·재시도·자동 재등록 차단을 구현했다. [삭제 계약](./서버_내_나의_데이터_삭제.md)을 따른다. 일반 보유기간은 1년으로 확정·구현했으며, 로그/백업·외부 SDK 삭제 절차는 아직 미확정이다.

## 검증 범위

- 안내 진입 4종과 복귀, 전체 알림 꺼짐/수동 위치에서 진입, 권한 바로가기 2종, 읽기 중 설정/권한 부수 효과 없음.
- 모든 본문·링크의 360px/2배 글씨 레이아웃, 공식 HTTPS 주소만 사용하는지, 사용자 식별값/인증값 미포함.
- 링크 성공/false/예외, 중복 누름 방지, 실패 시 주소 복사, 완료 전에 화면을 닫은 경우 처리.
- 2026-09-11 삭제 기능으로 서버 인증 API·DB 마이그레이션과 발송 전 존재 확인을 추가했다. 삭제 검증은 합성 설치만 사용하며 실제 사용자 데이터 삭제·테스트 알림 발송을 하지 않는다.
