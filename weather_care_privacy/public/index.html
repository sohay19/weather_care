02

어떤 정보를, 왜 처리하나요?

이용하는 기능과 권한 선택에 따라 처리하는 정보가 다릅니다. 이름·전화번호를 입력하는 회원가입 기능은 현재 없습니다.

지역 날씨와 생활 안내

항목 선택 지역과 날씨 격자, 위치 선택 방식, 위치 권한을 허용하고 해당 기능을 사용할 때의 위도·경도

목적 해당 지역의 날씨·강수·도로 관련 자료 조회와 생활 안내

방법 이용자의 지역 선택 또는 기기의 위치 기능으로 취득하여 필요한 앱 서버 요청에 전송

서버 등록과 날씨 알림

항목 설치 식별자, 등록 인증정보, FCM 푸시 토큰, 지역·위치 정보, 알림 설정, 플랫폼·앱 버전·시간대, 마지막 사용 확인 시각, 알림 발송 이력 및 중복 발송 방지 상태

목적 설치별 요청 인증, 알림 전달, 설정 동기화, 중복 알림 방지 및 데이터 삭제 처리

방법 앱과 서버의 통신, 알림 처리 과정에서 생성

앱 이용 통계 · 선택

항목 Firebase Analytics의 앱 이용 이벤트, 앱 인스턴스 관련 식별정보, 기기·운영체제·앱 정보 등 SDK 자동 수집 정보

광고 서비스 · 연결 준비 중

Google AdMob 및 UMP를 사용해 광고 관련 개인정보 선택을 확인하도록 구현했습니다. 현재 광고 표시 기능은 연결 전입니다. 광고 서비스의 기기·식별자·광고 상호작용·진단 정보 등 실제 처리 항목은 광고 적용 및 콘솔 검토 후 최종 방침에 명시합니다.

운영 방침은 다른 회사의 앱·웹사이트 활동 추적을 사용하지 않는 것입니다. 광고 동의와 앱 이용 통계 동의를 같은 선택으로 취급하지 않습니다.

문의 이메일을 보내는 경우 회신을 위해 발신 이메일과 문의 내용을 처리합니다. 문의 기록의 구체적인 보관기간은 최종 게시 전에 확정합니다.

03

동의와 권한은 선택할 수 있어요

  • 위치: 기기 설정에서 권한을 변경할 수 있습니다. 거부하면 현재 위치 자동 확인은 제한되지만 지역을 직접 선택할 수 있습니다.
  • 알림: 앱의 알림 설정과 기기 알림 권한을 통해 제어합니다. 알림을 끄는 것과 서버에 저장된 정보를 삭제하는 것은 다릅니다.
  • 이용 통계: ‘앱 이용 통계 수집 (선택)’을 켜고 동의한 뒤 수집을 시작합니다. 끄면 이후 수집 중단을 요청합니다. 미동의해도 날씨·알림 기능을 제한하지 않습니다. 오류가 표시되면 다시 시도하거나 문의해주세요.
  • 광고: UMP가 필요한 동의 화면을 표시하며, 요구되는 경우 설정에 ‘광고 개인정보 선택’이 나타납니다. 화면 표시 여부는 실제 이용 지역과 설정 등에 따라 달라집니다.

기기 권한이나 SDK 동의 철회는 이미 전송된 모든 자료의 즉시 삭제를 뜻하지 않습니다. 외부 서비스 자료와 앱 서버 자료는 처리 경로가 다릅니다.

04

얼마나 보관하고, 어떻게 삭제하나요?

설치 등록·위치·토큰·설정·인증정보
서버가 마지막으로 인증된 앱 사용을 확인한 뒤 1년 동안 사용이 확인되지 않으면 관련 데이터를 정리합니다. 그 전에 본인 확인된 삭제 요청을 하면 해당 설치의 관련 데이터를 삭제합니다.
알림 발송 이력
각 발송 시각부터 1년 보관 후 정리합니다. 설치 데이터 삭제 시 관련 발송 이력도 삭제합니다.
정리 주기
주기적 작업으로 정리하며 장애나 작업 적체로 지연될 수 있습니다. 만료 순간의 즉시 삭제를 보장하지 않습니다.
운영 로그와 복구 사본
Workers의 신규 로그 저장을 중단했습니다. 릴레이 전용 로그는 3일 보관 설정으로 운영하되 회전·정리 지연이 있을 수 있습니다. 기존 공용 로그는 별도 회전 규칙을 따릅니다. 무료 D1 복구 이력은 7일 기준이며, 복원된 개인 데이터를 운영에 재사용하지 않도록 정리·검증 후 서비스를 재개하는 절차를 둡니다.
기기에 남은 정보
지역 선택·체크 기록·동의 설정 등 기기 저장 정보는 서버 삭제와 별개입니다. 기기 및 앱의 데이터 삭제 기능으로 관리할 수 있습니다.
Firebase·Google 광고 자료
앱 서버의 1년 기준을 외부 서비스 전체에 적용하지 않습니다. 실제 서비스별 보관·삭제 조건과 콘솔 설정을 확인해 최종 방침에 반영합니다.

전자 정보는 해당 저장소에서 삭제하는 방식으로 처리합니다. 복구 사본·과거 로그·외부 서비스에 남은 정보까지 한 번의 서버 삭제로 즉시 영구 파기된다고 안내하지 않습니다.

05

외부 서비스와 국외 처리

다음 외부 서비스를 사용하거나 연결하고 있습니다. 계약상 수탁자·제3자 제공 해당 여부, 이전받는 법인과 연락처, 국가, 항목, 시기·방법, 보유기간, 적용 근거 및 거부 방법은 실제 계약·설정을 확인한 뒤 확정해야 합니다.

  • Cloudflare: 앱 API(Workers), 데이터베이스(D1), 이 안내 페이지(Pages) 제공.
  • Firebase: 푸시 알림(Cloud Messaging), 선택 동의 기반 이용 통계(Analytics).
  • Google AdMob / UMP: 광고 및 광고 관련 개인정보 선택 관리. 실제 광고 표시 연결은 준비 중.

한국 스토어에 배포하더라도 외부 서비스가 모든 정보를 한국에서만 처리한다는 의미는 아닙니다. 미확인 국가나 기간을 추정해 기재하지 않습니다.

06

정보 확인과 삭제 요청

개인정보 열람·정정·삭제·처리정지 또는 동의 철회에 관한 요청은 문의 이메일로 보내실 수 있습니다. 요청자 확인에 필요한 범위에서 안내하며, 다른 이용자의 정보를 공개하지 않습니다.

앱 서버 정보 직접 삭제
  1. 앱의 설정을 엽니다.
  2. 서버 내 나의 데이터 삭제를 선택합니다.
  3. 삭제 범위와 알림 중단 안내를 확인한 뒤 요청합니다.
  4. 완료 안내를 확인합니다. 통신 오류 시 완료로 간주하지 말고 재시도합니다.

삭제 후에는 명시적으로 ‘서버 기능 다시 사용’을 선택하기 전까지 해당 설치의 자동 재등록을 멈춥니다. 재사용 시 알림은 자동으로 켜지지 않습니다. 앱을 제거하거나 알림 권한만 끄는 것으로 서버 데이터가 즉시 삭제되지는 않습니다.

07

정보 보호와 이 페이지

앱 서버 요청은 암호화된 통신과 설치별 인증으로 보호하며, 서버에 저장된 인증정보의 해시를 이용해 접근을 확인합니다. 삭제·보유기간 정리와 운영 로그 최소화 절차를 적용합니다. 다만 모든 보안 위험이 제거되었다고 보장하지 않습니다.

이 페이지 자체에는 광고·Analytics·외부 폰트·추적 스크립트·입력 폼을 넣지 않았습니다. 페이지를 제공하는 Cloudflare는 접속 처리와 보안을 위해 IP 주소 등 네트워크 정보를 처리할 수 있습니다. 이메일 문의는 사용자의 메일 앱을 통해 전송됩니다.

최종 방침의 시행일과 변경 이력은 검토가 끝난 후 이 페이지에 표시합니다.
