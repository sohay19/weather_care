# 그래프 수치 겹침 개선 예시

이 폴더는 막대 내부에도 수치를 놓을 수 있다는 후속 요청 이전의 결과를 보존한다. 현재 적용 기준과 갱신한 1·2·3번은 [막대 내부 허용 예시](../chart-label-inside-bars-20261029/README.md)에 있다.

2026-10-29 수정한 실제 Flutter 그래프 위젯에 검사용 데이터를 넣어 화면을 띄우지 않고 렌더링한 결과다. 실기기 촬영이나 운영 날씨 자료가 아니다. 제품의 SUITE 한글 글꼴과 다크 테마를 사용했다.

| 파일 | 확인하는 상황 |
| --- | --- |
| 01-rain-peaks.png | 첨부 사례와 같은 강수량 1·0·0·2mm와 확률 60%, 급경사 선분 |
| 02-rain-extremes.png | 0%·100%, 선과 막대 끝 및 수치가 가까운 상황 |
| 03-snow-ranges.png | 신적설 범위, 현재 적설량, 강설확률, 서로 다른 관측 시각, 결측 |
| 04-temperature-crossing.png | 기온·체감온도의 교차·동일 값·영하와 날씨 아이콘 |
| 05-humidity.png | 2배 글씨에서 습도 0%·1%·99%·100% |

수치의 실제 글자 폭으로 선분·점·범위·막대·다른 수치와의 충돌을 검사한다. 겹쳐 그리는 확률 막대는 폭을 줄여 옆 공간을 확보했다. 확률은 막대 위를 우선 확보하고, 다른 수치는 같은 시간 열에서 가까운 빈 공간을 찾는다. 기온의 높은 값은 위, 낮은 값은 아래에 두며 날씨 아이콘도 수치와 함께 이동한다.

이동한 수치는 같은 색의 점선으로 원래 위치와 연결한다. 점선은 그래프 뒤에 그리고 수치·아이콘 영역을 제외해 다른 정보를 가리지 않는다. 열 안에 자리가 전혀 없으면 같은 시간 아래에 공간을 추가해 값을 보존한다. 현재 제품의 두 계열·세 계열 검사용 사례는 원래 차트 높이 안에 모두 들어간다.

## 검증

- 관련 7개 테스트 파일, 171개 검사 통과.
- 예시 5종 × 글씨 1배·2배, 세 계열의 동일 최댓값, 공간 부족 시 값 보존 검사.
- 고정 난수로 만든 16가지 24시간 자료: 급격한 증감·결측·불규칙 관측 시각·확률 0~100.
- 수치끼리, 수치와 아이콘, 수치와 막대·범위·선분·점의 겹침 및 차트 경계 검사.
- 기존 Main·Week 구간 중앙·자정·누락 시간, 강설 라이트·다크, 바다·하천 화면 회귀 검사 포함.
