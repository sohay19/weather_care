# 원본 결측·예보 풍향·주소정보 처리 기간 확인

후속 조사: [302격자의 지점별 예보 전수 성공과 풍향 제공 경로 대조](302격자_해결안_풍향_제공경로_확인_20261009.md). 아래의 ‘예보 283셀 결측’은 APIHub 전국 파일 기준이며, 공공데이터포털의 같은 격자 예보는 302개 모두 정상임을 추가 확인했다.

2026-10-09 조사. 운영 릴리스는 `20261009-national-cache`다. 이번에는 런타임 소스·타임아웃·수집 정책을 변경하거나 재배포하지 않았다. 운영 예산 보호를 거친 진단 11회, 원본 캐시·로그·공식 문서·신청 화면을 대조했다.

## 원본 자체 결측

파일 수집과 격자 값의 유효성은 다르다. 10분 실황은 각 변수의 149×253=37,697개 값을 저장했지만, 제공처가 넣은 `-99` 또는 `-999`는 기온·습도·풍속의 실제 수치로 사용할 수 없다. 이를 0이나 대표 격자 값으로 바꾸지 않는다.

SGIS 2025Q2 경계와 격자 영역의 교차 면적이 1㎡를 넘으면 검사 대상으로 포함했다. ‘육지 격자’는 육지가 조금이라도 걸치는 셀이며, 셀 전체가 육지이거나 행정동 1개라는 뜻이 아니다. 09:20 실황 결과:

| 구분 | 격자 수 |
|---|---:|
| 육지와 교차 | 4,728 |
| 기온·습도·풍속 모두 유효 | 4,426 |
| 세 변수 모두 `-99` | 283 |
| 세 변수 모두 `-999` | 19 |
| 합계 결측 | 302 |

저장된 116회차(10/7 23:50~10/9 09:20 KST)를 대조했으며, 이 302셀 중 핵심 관측값이 유효했던 셀은 0개다. 해당 기간의 모든 10분 회차가 연속 저장됐다는 뜻은 아니다.

결측 302셀 모두 육지 면적 비율 50% 미만이고, 288셀은 10% 미만이다. 301셀의 중심점은 SGIS 행정동 도형 밖이다. 중심점이 도형 안인 1셀은 `(42,52)`, 전라남도 진도군 조도면이며 육지 비율 약 2.67%다. 북측 접경 지역도 포함하므로 경계 밖 중심점이 모두 바다라는 뜻은 아니다.

**판단:** 지속적인 동일 셀 결측과 교차 형태는 기상청 실황 제공 영역과 우리 육지 교차 판정 범위의 차이를 시사한다. 기상청 내부 영역 마스크·관측소 연결·결측 생성 규칙은 확정하지 못했다. 2026 실제 경계는 다운로드 대기 중이므로 면적·지역 판정은 2025Q2 기준이다.

이 302셀의 10/9 08시 발표·10시 예보를 대조하면, 19셀은 예보 기온·습도·풍속을 사용할 수 있고 283셀은 예보 핵심값도 결측이다. 따라서 실황 결측이 모든 항목의 결측을 뜻하지 않는다. 지역명·자외선·대기질·시정 등은 해당 제공처의 지역·관측소 원본에 따라 별도로 사용할 수 있다. 실황끼리의 어제 동시각 비교는 실황이 없으면 만들 수 없고, 예보는 관측과 구분해야 한다.

전체 302셀의 지역·면적·중심점 판정: [지역 대조 JSON](원본결측_지역대조_20261009.json).

## 예보 풍향 8파일

대상은 10/9 05시 발표(`tmfc=2026100905`)의 풍향 `VEC`, 유효시각 `2026101203`, `06`, `09`, `12`, `15`, `18`, `21` 및 `2026101300`이다. 특정 지역의 요청 8개가 아니라 전국 파일 8개다.

공식 API는 VEC·UUU·VVV를 요청 변수로 안내하고 2024-11-28 이후 연장 구간을 제공한다고 설명한다. 연장일의 3시간 간격 및 강수량·적설·풍속의 정성 코드 변경은 명시돼 있으나, 풍향을 연장일에서 제외한다는 공식 안내는 찾지 못했다. [APIHub 규격](https://apihub.kma.go.kr/apiList.do?seqApi=10), [기상청 단기예보 설명](https://www.data.go.kr/dataset/15000099/fileData.do).

### 빈 응답

VEC는 기존 제공 구간의 마지막 시각까지 정상이고 연장 구간부터 빈 응답이다. 서로 다른 발표 3개에서도 같은 유효시각의 VEC가 비어 있고, 같은 발표·시각의 기온·풍속·바람성분은 제공된다. 오래전에 발표된 회차이므로 최신 발표 직후 준비 지연으로 설명되지 않는다.

직접 원인은 APIHub가 해당 VEC 파일의 본문을 제공하지 않는 것이다. HTTP 응답이 이미 0B여서 우리 인코딩·파서가 값을 버린 사례가 아니다. 동일 인증으로 다른 파일이 정상이며 인증·한도 초과 응답도 확인되지 않았다.

**추론:** VEC 연장 구간의 생성·게시·조회 경로 문제로 좁혀진다. 의도적인 미제공인지, 파일 생산 오류인지, 조회 프로그램이 이전 종료 시각을 적용하는지는 기상청 내부 확인이 필요하다. 이번에 외부 문의를 제출하지 않았다.

### 시간초과

별도 시간초과 2건은 DNS 완료 약 0.004초, TCP 완료 약 0.009~0.010초, TLS 완료 약 0.026~0.027초였다. 이후 첫 응답 바이트를 받지 못한 채 30초에 종료됐다. 파싱·DB 저장 전 단계다. 동일 요청 재조회는 정상이며 curl에서도 발생했으므로 Node fetch·파서만의 문제로 설명되지 않는다.

연결 이후 API 응답 대기 구간의 일시적 지연까지 확인됐다. 측정은 기상청 API 처리·응답 경로 지연을 시사하지만, 기상청 내부 부하·큐·파일 접근과 외부 응답 경로를 구분할 서버 측 로그는 없다. 우리 PC의 DNS·TCP·TLS 지연은 이 두 사례의 원인이 아니다. 11회 중 시간초과 2회는 작은 진단 실험이며 전체 운영 실패율이 아니다.

타임아웃 증가는 30초 이후 도착하는 응답에는 도움이 될 수 있으나 0B 응답은 해결하지 못한다. 재조회는 2초 이내 완료됐으며 사용자가 정한 운영 타임아웃 30초를 유지했다.

### 우리 서버 보완 상태와 방법

풍향까지 9개가 모두 있어야 다른 8개 예보를 조회하던 조건은 직전 작업에서 수정·배포 완료했다. 풍향만 `WIND_DIRECTION_UNAVAILABLE`, 나머지 같은 발표의 8개는 유지한다. 빈 본문은 `NO_USABLE_DATA`로 기록하고 기존 예산·임대를 지켜 재시도한다. 이번에는 추가 수정하지 않았다.

UUU/VVV 바람성분이 연장 구간에도 실제 제공됨을 확인했다. 풍향 복구 후보는 같은 발표·같은 유효시각의 두 성분으로 방향을 계산하는 방법이다. 단위·결측·무풍 처리와 정상 VEC 일치도 검증이 선행돼야 하며 이번에 계산값을 운영에 넣지 않았다. 대표 격자나 AWS 실황 교체 방식이 아니다.

진단 11회 장부 증가량은 4,047,782B(실제 본문 2,047,782B + 시간초과 예약 2,000,000B)다. 재시도 장부 87,085,906B→91,133,688B, 초기 100MB 상한 이내이며 예산 보호를 사용했다.

## 주소정보 ‘구역 구현’ 처리 기간

[2025-01-20 공식 답변](https://eng.juso.go.kr/addrlink/qna/qnaDetail.do?noticeMgtSn=133740&noticeType=QNA)은 전자지도 신청의 시군구·시도 자료 승인을 해당 지자체가 담당하고, **승인 후 1시간 뒤 신청내역에서 다운로드 가능**하다고 안내한다. 신청부터 승인까지 고정 일수는 제시하지 않고 담당 지자체에 일정을 확인하라고 한다.

이는 2025년 전자지도 안내이며 현재 2026년 ‘구역 구현’ 처리 기한으로 확정할 수 없다. 최신 공식 공개 검색에서도 별도의 고정 일수·완료 예상 시간은 찾지 못했다.

로그인된 실제 신청 화면에서 신청번호 47933, 구역 구현 16건, 기준월 2026년 9월, SHP, 모두 ‘처리중’, 다운로드 없음, 예상 완료 시각 미표시를 확인했다. 이 표시만으로 지자체 승인 대기인지 파일 생성 중인지 확정할 수 없다.

일정 확인 연락처는 도로명주소 도움센터 **1588-0061 → 7번**이다. 신청번호 47933과 ‘2026년 9월 구역 구현 전국 16건 처리중’을 함께 전달하면 해당 신청의 단계·예상 완료 시간을 확인할 수 있다. 전화·문의 등록은 이번에 진행하지 않았다.

오늘 10/9는 한글날이고 10/9~11은 주 5일 기관의 연휴다. 담당자 승인이 필요한 단계라면 다음 영업일인 10/12 이후로 진행이 늦어질 가능성이 있다. 이는 처리 단계가 승인 대기라는 확인이나 10/12 완료 보장이 아니다. [한국천문연구원 2026년 월력요항](https://www.kasi.re.kr/kor/post/newsMaterial/32031).
